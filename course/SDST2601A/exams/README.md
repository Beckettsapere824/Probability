# STAT2601 / SDST2601A Class Tests (transcribed)

Local + repo archive of past class tests used to calibrate node depth and exam difficulty.

## Layout
- `test1/` — counting, classical probability, early discrete (many years)
- `test2/` — discrete distributions, expectation, conditional, early continuous
- `test3/` — continuous, joint, transforms, survival/hazard, later topics

Full transcribed markdown files live under the project artifacts mirror and will be synced node-by-node as needed.

## Difficulty signal (for node authors)
- Heavy on exact counting + conditional probability under restrictions
- Memorylessness, waiting-time versions of geometric/negative binomial appear often
- Joint continuous support geometry + marginal/conditional must be computed by hand
- Hazard / survival integrals appear in test3
- MCQ often has near options; exact fractions and careful support matter
- Section B style demands full derivation, not formula recall

**Authoring rule:** nodes must support this level — intuition → derivation → exam-style worked example → common trap. Do not compress to formula-only.
