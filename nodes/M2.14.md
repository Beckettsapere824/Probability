# M2.14 Digit Permutation Sums / 数字排列求和

**Prerequisites / 前置**: [M0.3](M0.3.md)

**Source anchors**: each digit appears equally often in each place; place-value factorisation.

---

## What problem are we solving? / 我们要解决什么问题？

Sum of all distinct numbers obtained by permuting a given set of digits.

对给定数字的所有不同排列所成整数求和。

---

## Step 1: Frequency per place / 第一步：各位频率

Each digit appears in each place in $(n-1)!$ of the $n!$ numbers (distinct digits).

---

## Step 2: Place contribution / 第二步：位权贡献

Place $10^{p}$ contributes $(n-1)!(\sum d_i)\times 10^{p}$.

---

## Step 3: Hand check / 第三步：手算

Digits 1,2,3: each place sum $12$; total $12\times111=1332$.

---

## Must-build intuitions / 必须建立的直觉

1. Linearity by place value.  
2. Equal frequency of each digit in each place.  
3. Repeated digits: adjust by multiset factorials.  
4. Same idea for summing constrained digit strings.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Listing all permutations for $n\ge5$ | Use frequency argument |
| Forgetting place weights | Multiply by $10^{p}$ |
| Ignoring repeated digits | Adjust factorial |

---
