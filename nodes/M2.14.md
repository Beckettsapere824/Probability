# M2.14 Digit Permutation Sums / 数字排列求和

**Prerequisites / 前置**: [M0.3 Factorials, Permutations, Combinations](M0.3.md)

---

## Content / 内容

To obtain the sum of all distinct numbers formed by permuting a given set of digits, fix one digit in a given place and permute the remaining digits freely. Each digit appears equally often in each place. The total sum is therefore (sum of the digits) × (place values) × (number of times each digit appears in a fixed place).

求给定数字集所有不重复排列形成的数之和时，固定某一数字在某一数位，其余数字全排列。每个数字在每个数位出现次数相同。总和 = 数字和 × 位权之和 × 每个数字在固定位出现的次数。

If zero is among the digits the leading-place count must be adjusted (leading zero is usually forbidden).

若数字含 0，则首位计数需调整（通常禁止前导零）。

## Example / 例子

Digits 1,2,3. All permutations: 123,132,213,231,312,321. Sum = 1332. Each digit appears twice in each place; (1+2+3)×(100+10+1)×2 = 1332.

数字 1,2,3。所有排列：123,132,213,231,312,321。和 = 1332。每位每个数字出现两次；(1+2+3)×(100+10+1)×2 = 1332。

## Practice Problem / 练习题

What is the sum of all distinct 3-digit numbers that can be formed with the digits 1,2,3,4 (no repetition)?

用数字 1,2,3,4（不重复）能组成的所有不同三位数之和是多少？

<details>
<summary>Solution sketch / 解答提示</summary>

Each place has each digit appearing P(3,2)=6 times. Sum = (1+2+3+4)×(100+10+1)×6 = 6666.

每位每个数字出现 P(3,2)=6 次。和 = (1+2+3+4)×(100+10+1)×6 = 6666。

</details>
