# M5.3 Conditional Counting (seating) / 条件计数

**Prerequisites / 前置**: [M1.3](M1.3.md), [M2.4](M2.4.md)

**Source anchors**: classical probability under a restricted sample space; seating with conditions.

---

## What problem are we solving? / 我们要解决什么问题？

Given a restriction (e.g. two people already sit together), the sample space shrinks. Probabilities become **conditional counts**: favorable outcomes inside the restricted universe over size of that universe.

有限制时样本空间缩小；概率 = 限制下有利结果数 / 限制后总结果数。

---

## Step 1: Identify the restricted $\Omega$ / 第一步：确定限制后的 $\Omega$

Conditioning event $B$ defines a new equally likely universe if the original model was classical. $|\Omega_B|=$ number of outcomes in $B$.

---

## Step 2: Count favorable inside $B$ / 第二步：在 $B$ 内计数

$\Pr(A\mid B)=|A\cap B|/|B|$ under uniformity on the original atoms.

---

## Step 3: Hand idea / 第三步：思路

“Two particular seats are already taken by a couple treated as a block” → treat block as one unit, count permutations of the reduced set, then form ratios.

---

## Must-build intuitions / 必须建立的直觉

1. Conditioning = reweight / restrict the classical space.  
2. Same counting tools (blocks, gaps) apply inside $B$.  
3. Write $A\cap B$ carefully — do not count outside $B$.  
4. Equivalent to definition $\Pr(A\cap B)/\Pr(B)$ with both via counting.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Using unrestricted $|\Omega|$ in the denominator | Denominator is $|B|$ |
| Double-counting the condition | Define $B$ once |
| Mixing ordered/unordered models mid-way | Stay consistent |
