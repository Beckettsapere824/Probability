# M2.6 Inclusion-Exclusion, Non-empty Boxes, Surjections / 容斥原理、非空盒子、满射计数

**Prerequisites / 前置**: [M1.2 Complement, Union, Inclusion-Exclusion](M1.2.md), [M0.3 Factorials, Permutations, Combinations](M0.3.md)

---

## Content / 内容

The number of ways to put n distinguishable balls into r distinguishable boxes with no box empty is
Σ_{j=0}^r (-1)^j C(r,j) (r-j)^n
(the surjection count). The same formula counts the number of surjective functions from an n-set onto an r-set.

n 个可区分球放入 r 个可区分盒子且无空盒的方式数为
Σ_{j=0}^r (-1)^j C(r,j) (r-j)^n
（满射数）。同一公式计数从 n 元集到 r 元集的满射。

When balls of the same color are indistinguishable one first allocates each color by stars-and-bars and then applies inclusion-exclusion on the boxes. Allocations of different colors multiply because they are independent.

同色球不可区分时，先按颜色用 stars-and-bars 分配，再对盒子做容斥。不同颜色的分配独立相乘。

## Example / 例子

Number of surjections from a 3-set onto a 2-set: C(2,0)2^3 - C(2,1)1^3 = 8 - 2 = 6.

从 3 元集到 2 元集的满射数：C(2,0)2^3 - C(2,1)1^3 = 8 - 2 = 6。

## Practice Problem / 练习题

How many ways can 5 distinct people be assigned to 3 distinct rooms so that no room is empty?

5 个不同的人分配到 3 个不同房间且无空房，有多少种方式？

<details>
<summary>Solution sketch / 解答提示</summary>

Σ (-1)^j C(3,j) (3-j)^5 = 3^5 - C(3,1)2^5 + C(3,2)1^5 = 243 - 96 + 3 = 150.

Σ (-1)^j C(3,j) (3-j)^5 = 3^5 - C(3,1)2^5 + C(3,2)1^5 = 243 - 96 + 3 = 150。

</details>
