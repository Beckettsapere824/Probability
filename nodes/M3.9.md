# M3.9 Moment Generating Function (MGF) / 矩母函数 MGF

**Prerequisites / 前置**: [M3.1 Expectation](M3.1.md), [M0.6 Derivatives and MGF](M0.6.md)

---

## Content / 内容

The moment generating function of X is M_X(t) = E(e^{tX}). For a discrete random variable it is the sum Σ e^{tx} p(x). Differentiation under the sum (justified inside the radius of convergence) yields the moments: M^{(r)}(0) = E(X^r).

X 的矩母函数为 M_X(t) = E(e^{tX})。离散情形是和 Σ e^{tx} p(x)。在收敛半径内对和求导得到矩：M^{(r)}(0) = E(X^r)。

The domain of convergence is determined by the values of t for which the defining series converges absolutely. For the logarithmic-series distribution the MGF is ln(1−p e^t)/ln(1−p) with t < −ln p.

收敛域由使定义级数绝对收敛的 t 值决定。对数级数分布的 MGF 为 ln(1−p e^t)/ln(1−p)，t < −ln p。

## Example / 例子

Bernoulli(p): M(t) = 1−p + p e^t. Geometric (starting at 1): M(t) = p e^t / (1−(1−p)e^t) for t < −ln(1−p).

Bernoulli(p)：M(t) = 1−p + p e^t。几何（从 1 开始）：M(t) = p e^t / (1−(1−p)e^t)，t < −ln(1−p)。

## Practice Problem / 练习题

Write the MGF of a discrete uniform random variable on {1,2,3}.

写出 {1,2,3} 上离散均匀随机变量的 MGF。

<details>
<summary>Solution sketch / 解答提示</summary>

M(t) = (e^t + e^{2t} + e^{3t})/3.

M(t) = (e^t + e^{2t} + e^{3t})/3。

</details>
