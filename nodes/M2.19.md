# M2.19 Non-uniform Dice, Discrete Convolution and Enumeration / 非均匀骰子、离散卷积与枚举

**Prerequisites / 前置**: [M2.12 Generating Functions](M2.12.md)

---

## Content / 内容

When faces have unequal probabilities the ordinary generating function carries the probability weights instead of the uniform 1. The coefficient of x^s in the product of the individual face generating functions gives the probability (or the weighted count) of total s. Difference conditions such as (a-b)(b-c)=0 or =2 are handled by enumerating the admissible difference values.

当面概率不等时，普通生成函数携带概率权重而非均匀的 1。各面生成函数乘积中 x^s 的系数给出总和为 s 的概率（或加权计数）。差条件如 (a-b)(b-c)=0 或 =2 通过枚举合法差值处理。

A fair die has total outcomes 6^n; a non-uniform die weights each face differently. Consecutive identical faces are often counted via the complement. When enumerating, fix one variable first and then count the possibilities for the others.

公平骰总结果 6^n；非均匀骰每面权重不同。连续同面常用补事件计数。枚举时先固定一个变量，再数其余。

## Example / 例子

Two fair dice. Generating function (x+x^2+…+x^6)^2; coefficient of x^7 is 6. For a die with faces weighted 1,2,3,4,5,6 the same coefficient extraction works after inserting the weights.

两枚公平骰。(x+x^2+…+x^6)^2；x^7 系数 6。对面权重为 1,2,3,4,5,6 的骰子，插入权重后同样提取系数。

## Practice Problem / 练习题

A die has P(face k) proportional to k for k=1…6. Write the probability generating function for a single roll and find the probability that the face is even.

某骰子 P(面 k) 与 k 成正比（k=1…6）。写出单次投掷的概率生成函数，并求面为偶数的概率。

<details>
<summary>Solution sketch / 解答提示</summary>

Normalizing constant 21. PGF = (x+2x^2+3x^3+4x^4+5x^5+6x^6)/21. P(even) = (2+4+6)/21 = 12/21 = 4/7.

归一化常数 21。PGF = (x+2x^2+3x^3+4x^4+5x^5+6x^6)/21。P(偶数) = (2+4+6)/21 = 12/21 = 4/7。

</details>
