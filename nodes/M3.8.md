# M3.8 Correlation Interpretation / 相关系数解读

**Prerequisites / 前置**: [M3.12](M3.12.md)

**Source anchors**: $\rho=\mathrm{Cov}/(\sigma_X\sigma_Y)$; $\rho=\pm1$ perfect linear; $\rho=0$ uncorrelated.

---

## What problem are we solving? / 我们要解决什么问题？

Interpret Pearson correlation: scale-free measure of **linear** association.

解读相关系数：无量纲的线性关联度量。

---

## Step 1: Definition / 第一步：定义

$$\rho=\frac{\mathrm{Cov}(X,Y)}{\sigma_X\sigma_Y}\in[-1,1].$$

---

## Step 2: Extremes / 第二步：极端

$|\rho|=1$ iff $Y=aX+b$ a.s. with $a\neq 0$.

---

## Step 3: Zero / 第三步：为零

$\rho=0$ ⇔ uncorrelated; nonlinear dependence can still exist.

---

## Must-build intuitions / 必须建立的直觉

1. Correlation is dimensionless.  
2. $\rho$ only sees linear association.  
3. Independence ⇒ $\rho=0$; converse false.  
4. Affine maps of each variable preserve $|\rho|$.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| $\rho=0$ ⇒ independent | Counterexamples |
| $|\rho|$ measures any dependence | Only linear |
| Comparing Cov across scales | Use $\rho$ |
