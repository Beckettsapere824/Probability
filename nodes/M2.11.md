# M2.11 Derangements and Exactly k Fixed Points / 错排与恰好 k 个正确

**Prerequisites / 前置**: [M0.3 Factorials, Permutations, Combinations](M0.3.md), [M1.9 Classical Probability](M1.9.md)

---

## Content / 内容

The number of derangements (permutations with no fixed points) of n objects is
D_n = n! Σ_{j=0}^n (-1)^j / j! .
The recurrence D_n = (n-1)(D_{n-1} + D_{n-2}) also holds. The number of permutations with exactly k fixed points is C(n,k) D_{n-k}.

n 个对象的错排数（无不动点的排列）为
D_n = n! Σ_{j=0}^n (-1)^j / j! 。
递推 D_n = (n-1)(D_{n-1} + D_{n-2}) 也成立。恰好 k 个不动点的排列数为 C(n,k) D_{n-k}。

As n → ∞ one has D_n / n! → e^{-1}. Do not confuse the derangement count with the total number of permutations.

n → ∞ 时 D_n / n! → e^{-1}。不要把错排数与全排列数混淆。

## Example / 例子

D_3 = 2, D_4 = 9. Probability that a random permutation of 4 items is a derangement is 9/24 = 3/8.

D_3 = 2，D_4 = 9。4 项随机排列为错排的概率 9/24 = 3/8。

## Practice Problem / 练习题

What is the probability that a random permutation of 5 letters has exactly 2 fixed points?

5 个字母的随机排列恰好有 2 个不动点的概率是多少？

<details>
<summary>Solution sketch / 解答提示</summary>

C(5,2) D_3 / 5! = 10 · 2 / 120 = 1/6.

C(5,2) D_3 / 5! = 10 · 2 / 120 = 1/6。

</details>
