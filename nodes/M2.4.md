# M2.4 Positive Integer Solutions and Inequality Slack / 正整数解与不等式松弛

**Prerequisites / 前置**: [M2.3 Stars and Bars](M2.3.md)

---

## Content / 内容

To solve x_i ≥ 1, substitute y_i = x_i - 1 (y_i ≥ 0). The equation becomes a non-negative one whose solution count is C(n-1, r-1) for the positive case of sum = n with r variables.

解 x_i ≥ 1 时令 y_i = x_i - 1（y_i ≥ 0）。方程变为非负方程，正整数情形（r 变量和为 n）解数为 C(n-1, r-1)。

An inequality x+y+z < 25 is rewritten x+y+z ≤ 24; a non-negative slack s turns it into an equation. The number of solutions of the inequality equals the number of non-negative solutions of the resulting equation.

不等式 x+y+z < 25 改写为 x+y+z ≤ 24；加非负松弛 s 成等式。不等式解数等于所得等式的非负解数。

Summation identities can collapse several such counts into a single binomial coefficient.

求和恒等式可把多组解数合并成单个组合数。

## Example / 例子

Positive solutions of x+y+z = 5: C(4,2) = 6. Non-negative solutions of x+y+z ≤ 4: introduce s ≥ 0, x+y+z+s = 4 → C(7,3) = 35.

x+y+z = 5 的正整数解：C(4,2) = 6。x+y+z ≤ 4 的非负解：加 s ≥ 0 得和为 4 → C(7,3) = 35。

## Practice Problem / 练习题

Find the number of positive integer solutions of x+y+z+w = 12.

求 x+y+z+w = 12 的正整数解个数。

<details>
<summary>Solution sketch / 解答提示</summary>

C(12-1,4-1) = C(11,3) = 165.

C(12-1,4-1) = C(11,3) = 165。

</details>
