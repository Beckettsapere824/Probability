# M0.4a Binomial Theorem and Coefficient Extraction / 二项式定理与系数提取

**Prerequisites / 前置**: [M0.3 Factorials, Permutations, Combinations](M0.3.md), [M0.4 Binomial Coefficient Identities](M0.4.md)

---

## Content / 内容

The binomial theorem states (a+b)^n = Σ_{k=0}^n C(n,k) a^k b^{n-k}. The special case (1+x)^n = Σ_{k=0}^n C(n,k) x^k is the ordinary generating function for the sequence C(n,k).

二项式定理：(a+b)^n = Σ_{k=0}^n C(n,k) a^k b^{n-k}。特例 (1+x)^n = Σ_{k=0}^n C(n,k) x^k 是序列 C(n,k) 的普通生成函数。

The coefficient of x^r in (1+x)^k is exactly C(k,r). Combined with the hockey-stick identity one can extract coefficients of more complicated sums. The same theorem collapses sums of the form Σ C(n,k) q^{n-k} into (1+q)^n.

(1+x)^k 中 x^r 的系数恰好是 C(k,r)。与 hockey-stick 联用可提取更复杂和的系数。同一定理把 Σ C(n,k) q^{n-k} 收成 (1+q)^n。

Multinomial coefficients generalize the binomial theorem to (x_1 + … + x_r)^n; the coefficient of x_1^{a_1} … x_r^{a_r} is n! / (a_1! … a_r!) provided the exponents sum to n.

多项式系数把二项式定理推广到 (x_1 + … + x_r)^n；x_1^{a_1} … x_r^{a_r} 的系数为 n! / (a_1! … a_r!)（指数之和为 n）。

## Example / 例子

Coefficient of x^3 in (1+x)^7 is C(7,3) = 35. Sum Σ_{k=0}^5 C(5,k) 2^{5-k} = (1+2)^5 = 243.

(1+x)^7 中 x^3 的系数是 C(7,3) = 35。求和 Σ_{k=0}^5 C(5,k) 2^{5-k} = (1+2)^5 = 243。

## Practice Problem / 练习题

Find the coefficient of x^4 in (1+x+x^2)^3 by expanding or by multinomial reasoning. Verify by enumerating the non-negative integer solutions of a+b+c=4 with each variable ≤ 2.

求 (1+x+x^2)^3 中 x^4 的系数（展开或用多项式系数）。通过枚举 a+b+c=4 且每变量 ≤2 的非负整数解来验证。

<details>
<summary>Solution sketch / 解答提示</summary>

Possible exponent triples (a,b,c) with a+b+c=4, 0≤ each ≤2: (2,2,0) and permutations (3 of them), (2,1,1) and permutations (3 of them). Multinomial coefficients give 3·(3!/(2!2!0!)) + 3·(3!/(2!1!1!)) = 3·3 + 3·3 = 18.

可能的指数三元组 (a,b,c) 满足 a+b+c=4 且各 ≤2：(2,2,0) 及其排列（3 个），(2,1,1) 及其排列（3 个）。多项式系数给出 3·(3!/(2!2!0!)) + 3·(3!/(2!1!1!)) = 3·3 + 3·3 = 18。

</details>
