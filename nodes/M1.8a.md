# M1.8a Merging Equal PMF Values and Constructing the Step-Function CDF / PMF 同值合并与 CDF 阶梯构造

**Prerequisites / 前置**: [M1.8 Random Variables, PMF, CDF](M1.8.md)

---

## Content / 内容

Different sample-space outcomes may map to the same numerical value of X. Their probabilities must be added together; one must never list the same x more than once in the PMF table.

不同样本结果可能映射到同一个数值 X = x。它们的概率必须合并；PMF 表中绝不能重复列出同一个 x。

First list every distinct attainable value of X, then for each value collect all sample outcomes that produce it and sum their probabilities. The CDF is obtained by ordering the values from smallest to largest and forming the running sum F(x) = Σ_{u ≤ x} p(u). Between consecutive attainable points F is constant; at each attainable point it jumps by the size of the PMF.

先列出 X 的所有可能取值，再对每个值收集产生它的样本组合并求和。CDF 按取值从小到大累加 F(x) = Σ_{u ≤ x} p(u)。相邻取值之间 F 保持不变；在每个取值点跳跃高度为 p(x)。

Always verify the three global properties: F(-∞) = 0, F(+∞) = 1, and monotonicity. Write the CDF piecewise according to the ordered support points.

始终检查三个全局性质：F(-∞) = 0，F(+∞) = 1，单调不减。按有序支撑点分段写出 CDF。

## Example / 例子

Two fair dice. Let X = sum. The outcome (1,6) and (2,5) both give X = 7; their probabilities are added. The PMF at 7 is 6/36.

两枚公平骰子。设 X = 点数和。(1,6) 与 (2,5) 都给出 X = 7；概率相加。7 处的 PMF 为 6/36。

## Practice Problem / 练习题

An urn contains 2 red and 3 blue balls. Two balls are drawn without replacement. Let X = number of red balls obtained. Construct the PMF and the piecewise CDF.

瓮中有 2 红 3 蓝。无放回抽两球。设 X = 抽到的红球数。构造 PMF 与分段 CDF。

可能取值 0,1,2。p(0)=3/10，p(1)=6/10，p(2)=1/10。F(x)=0 (x<0)，3/10 (0≤x<1)，9/10 (1≤x<2)，1 (x≥2)。
