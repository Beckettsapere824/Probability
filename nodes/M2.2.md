# M2.2 Subset Selection and Binary Choice / 子集选择与二进制选择

**Prerequisites / 前置**: [M0.3 Factorials, Permutations, Combinations](M0.3.md)

---

## Content / 内容

Each of k distinct objects may be included or excluded, giving 2^k possible subsets (including the empty set and the full set). This models ingredient combinations, feature selections, and any collection of independent yes/no decisions.

每个对象可选或不选，k 个可区分对象共有 2^k 种子集（含空集与全集）。这模拟配料组合、特征选择以及任何独立的是/否决策。

When two identical objects are allowed and order does not matter, the simple 2^k count no longer applies; one must switch to multiset enumeration.

当两个对象可以相同且无序时，简单的 2^k 不再适用，需改用多重集合计数。

## Example / 例子

A pizza may include or omit each of 4 toppings: 2^4 = 16 possible pizzas (including plain). Choosing any subset of {a,b,c} yields 8 possibilities.

比萨可加或不加 4 种配料：2^4 = 16 种（含原味）。从 {a,b,c} 选任意子集得 8 种可能。

## Practice Problem / 练习题

How many subsets of an n-element set have even cardinality? (Hint: (1+1)^n and (1-1)^n.)

n 元集有多少个偶数基数的子集？（提示：(1+1)^n 与 (1-1)^n。）

<details>
<summary>Solution sketch / 解答提示</summary>

(1+1)^n = 2^n = total subsets. (1-1)^n = 0 = even-cardinality minus odd-cardinality. Hence each is 2^{n-1}.

(1+1)^n = 2^n = 总子集数。(1-1)^n = 0 = 偶数基数减奇数基数。故各为 2^{n-1}。

</details>
