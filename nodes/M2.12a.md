# M2.12a Distinguishing “At-least / Positive / Non-negative” Generating-Function Factors / 生成函数因子的“至少/正/非负”区别

**Prerequisites / 前置**: [M2.12 Ordinary Generating Functions](M2.12.md)

---

## Content / 内容

- Non-negative even: 1 + x^2 + x^4 + … = 1/(1-x^2)
- Positive odd: x + x^3 + x^5 + … = x/(1-x^2)
- Non-negative multiples of 3: 1 + x^3 + x^6 + … = 1/(1-x^3)
- Positive multiples of 3: x^3/(1-x^3)

“At least one” can be obtained either by subtracting the constant term 1 from a non-negative factor or by writing the positive factor directly. When several independent types are chosen the overall generating function is the product of the individual factors.

- 非负偶数：1 + x^2 + x^4 + … = 1/(1-x^2)
- 正奇数：x + x^3 + x^5 + … = x/(1-x^2)
- 非负 3 的倍数：1 + x^3 + x^6 + … = 1/(1-x^3)
- 正 3 的倍数：x^3/(1-x^3)

“至少一个”可通过从非负因子减去常数项 1 得到，或直接写正因子。多类独立选择时总生成函数为各因子乘积。

In a ball-selection problem the phrase “orange balls must be an odd positive number” produces the factor x/(1-x^2), not 1/(1-x^2).

取球题中“橙球必须取奇数个且至少一个”的因子是 x/(1-x^2)，不是 1/(1-x^2)。

## Example / 例子

Red: 0 or 1 → 1+x. Green: any even number → 1/(1-x^2). Coefficient of x^4 in (1+x)/(1-x^2) gives the number of ways.

红：0 或 1 → 1+x。绿：任意偶数 → 1/(1-x^2)。(1+x)/(1-x^2) 中 x^4 的系数即方式数。

## Practice Problem / 练习题

Write the generating function for the number of orange balls that must be positive and odd, and for purple balls that must be a non-negative multiple of 3.

写出“橙球必须为正奇数”以及“紫球必须为非负 3 的倍数”的生成函数因子。

<details>
<summary>Solution sketch / 解答提示</summary>

Orange: x/(1-x^2). Purple: 1/(1-x^3).

橙：x/(1-x^2)。紫：1/(1-x^3)。

</details>
