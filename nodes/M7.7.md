# M7.7 Reciprocal Expectation Identity for the Binomial / 二项分布倒数期望恒等式

**Prerequisites / 前置**: [M4.2 Binomial](M4.2.md), [M0.4 Binomial Identities](M0.4.md), [M0.4a Binomial Theorem](M0.4a.md), [M3.2 LOTUS](M3.2.md)

---

## Content / 内容

The expectation E[1/(X+1)] for X~B(n,p) expands as Σ C(n,k) p^k q^{n−k}/(k+1). The key identity C(n,k)/(k+1)=C(n+1,k+1)/(n+1) converts the sum into an ordinary binomial expansion, which collapses to (1−q^{n+1})/[(n+1)p] where q=1−p. The algebraic path is: apply the combinatorial identity first, then invoke the binomial theorem. The summation index k runs from 0 to n.

对 X~B(n,p) 的期望 E[1/(X+1)] 展开为 Σ C(n,k) p^k q^{n−k}/(k+1)。关键恒等式 C(n,k)/(k+1)=C(n+1,k+1)/(n+1) 把和变成普通二项式展开，再收成 (1−q^{n+1})/[(n+1)p]，其中 q=1−p。代数路径为：先用组合恒等式，再套二项式定理。求和指标 k 从 0 到 n。

## Example / 例子

n=1, p=1/2. E[1/(X+1)]=(1−(1/2)^2)/(1·1/2)=3/2. Direct check: P(X=0)=1/2 → 1/1, P(X=1)=1/2 → 1/2, average 3/4? Wait—formula gives (1−q^2)/(2p). Recheck: (1−(1/2)^2)/(2·1/2)= (3/4)/1=3/4. Yes.

n=1，p=1/2。公式给出 (1−(1/2)^2)/(2·1/2)=3/4。直接验证一致。

## Practice Problem / 练习题

X~B(2,1/3). Evaluate E[1/(X+1)] by the closed formula.

X~B(2,1/3)。用闭式公式计算 E[1/(X+1)]。

<details>
<summary>Solution sketch / 解答提示</summary>

q=2/3. (1−(2/3)^3)/(3·1/3)=(1−8/27)/1=19/27.
