# M3.9a MGF Moment Formulae and Convergence Domain / MGF 求矩公式与收敛域

**Prerequisites / 前置**: [M3.9 Moment Generating Function](M3.9.md)

---

## Content / 内容

From the definition M_X(t) = E(e^{tX}) one obtains M'(0) = E(X) and M''(0) = E(X^2). Variance is then recovered by Var(X) = M''(0) − [M'(0)]^2. Composite differentiation is needed for expressions such as d/dt ln(1−p e^t) = −p e^t/(1−p e^t).

由定义 M_X(t) = E(e^{tX}) 得 M'(0) = E(X)，M''(0) = E(X^2)。方差随之由 Var(X) = M''(0) − [M'(0)]^2 得到。复合求导对形如 d/dt ln(1−p e^t) = −p e^t/(1−p e^t) 的表达式是必需的。

The convergence domain is found by solving the inequality that makes the series absolutely convergent (for the logarithmic series, |p e^t| < 1 yields t < −ln p). The recommended derivation path for the logarithmic-series distribution is: verify normalisation via the log series → write the MGF → differentiate → evaluate at t = 0.

收敛域通过解使级数绝对收敛的不等式得到（对数级数情形 |p e^t| < 1 给出 t < −ln p）。对数级数分布的推荐推导路径：用对数级数验证归一化 → 写 MGF → 求导 → 在 t = 0 处取值。

## Example / 例子

For M(t) = p e^t / (1−q e^t) one recovers E = 1/p and Var = q/p^2 after two differentiations at the origin.

对 M(t) = p e^t / (1−q e^t) 在原点求导两次后恢复 E = 1/p，Var = q/p^2。

## Practice Problem / 练习题

Given M(t) = ln(1−p e^t)/ln(1−p), compute the first derivative at t = 0 (the mean of the logarithmic-series distribution).

给定 M(t) = ln(1−p e^t)/ln(1−p)，计算 t = 0 处的一阶导数（对数级数分布的均值）。

<details>
<summary>Solution sketch / 解答提示</summary>

M'(t) = [1/ln(1−p)] · (−p e^t)/(1−p e^t). M'(0) = −p / [ln(1−p)·(1−p)].

M'(t) = [1/ln(1−p)] · (−p e^t)/(1−p e^t)。M'(0) = −p / [ln(1−p)·(1−p)]。

</details>
