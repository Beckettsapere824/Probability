# M7.3 Class Size: Professor Average versus Student Average / 班级大小：教授平均 vs 学生平均

**Prerequisites / 前置**: [M3.6 Weighted Averages and Size-biased Sampling](M3.6.md)

---

## Content / 内容

The average class size computed by averaging over classes (the professor’s perspective) is Σ n f_n. The average class size experienced by a randomly chosen student is the size-biased mean Σ n·(n f_n)/Σ n f_n. Both numbers are factually correct; they simply refer to different sampling frames. Large classes are over-represented in the student average precisely because more students sit in them. The weights of any weighted average must sum to 1 (or be normalised). The phrase “average class size faced by a student” is the canonical example of size-biasing.

按班级平均得到的班级规模（教授视角）为 Σ n f_n。随机抽取的学生所经历的平均班级规模是 size-biased 均值 Σ n·(n f_n)/Σ n f_n。两个数字都真实正确；它们只是对应不同的抽样框架。大班在学生平均中被过度代表，正是因为更多学生坐在其中。任何加权平均的权重必须和为 1（或先归一化）。“学生面临的平均班级规模”是 size-biasing 的经典例子。

## Example / 例子

Frequencies that produce professor average 25 and student average 53.2 appear in the original data set; the discrepancy is explained entirely by size-biasing.

产生教授平均 25、学生平均 53.2 的频率出现在原始数据中；差异完全由 size-biasing 解释。

## Practice Problem / 练习题

Classes of size 10 and 30 occur with equal frequency. Compute both averages.

规模 10 与 30 的班级等频出现。计算两种平均。

<details>
<summary>Solution sketch / 解答提示</summary>

Professor: 20. Student: (10²+30²)/(10+30)=25.

教授：20。学生：(10²+30²)/(10+30)=25。

</details>
