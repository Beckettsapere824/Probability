# M2.17 Unordered Selections with Repetition / Multisets / 无序可重复选择/多重集合

**Prerequisites / 前置**: [M2.1 Sampling Models](M2.1.md), [M2.3 Stars and Bars](M2.3.md)

---

## Content / 内容

The number of ways to choose k elements from n types with repetition allowed and order irrelevant is C(n+k-1,k). The same count enumerates non-decreasing sequences of length k from an n-element ordered set. Two identical objects that are regarded as interchangeable are counted by multisets, not by a naïve product of power-set sizes.

从 n 类中可重复无序选 k 个的方式数为 C(n+k-1,k)。同一计数也枚举从 n 元有序集中长度为 k 的非降序列。两个相同且可互换的对象用多重集合计数，而不是简单的幂集大小乘积。

Stars-and-bars and multiset counting are interchangeable via a simple translation. Always decide first whether repetition is allowed and whether order matters.

Stars-and-bars 与多重集合计数可通过简单翻译互换。始终先判断“可重复”和“无序”两个条件。

## Example / 例子

Number of non-decreasing triples (a,b,c) with 1 ≤ a ≤ b ≤ c ≤ 6 equals C(6+3-1,3) = C(8,3) (or equivalently the number of multisets of size 3 from 6 faces).

1 ≤ a ≤ b ≤ c ≤ 6 的非降三元组个数等于 C(6+3-1,3) = C(8,3)（或等价于从 6 个面中可重复选 3 个的多重集合数）。

## Practice Problem / 练习题

How many distinct non-decreasing sequences of length 3 can be formed from the set {1,2,3,4}?

从集合 {1,2,3,4} 能形成多少个长度为 3 的不同非降序列？

<details>
<summary>Solution sketch / 解答提示</summary>

C(4+3-1,3) = C(6,3) = 20.

C(4+3-1,3) = C(6,3) = 20。

</details>
