# M2.17 Multisets / 多重集

**Prerequisites / 前置**: [M2.5](M2.5.md)

**Source anchors**: stars and bars; $\binom{n+k-1}{k}$ unordered samples with repetition.

---

## What problem are we solving? / 我们要解决什么问题？

Number of ways to choose $k$ elements from $n$ types **with repetition allowed, order irrelevant** (multisets of size $k$).

从 $n$ 种中有放回、无序地选 $k$ 个：多重集个数。

---

## Step 1: Stars and bars / 第一步：隔板法

$$\binom{n+k-1}{k}=\binom{n+k-1}{n-1}.$$

---

## Step 2: Hand check / 第二步：手算

3 bagels from 4 types: $\binom{3+4-1}{3}=20$.

---

## Step 3: vs combinations / 第三步：对比

Without repetition: $\binom{n}{k}$. With repetition unordered: stars and bars. With repetition ordered: $n^k$.

---

## Must-build intuitions / 必须建立的直觉

1. Multiset = nonnegative integer solutions to $x_1+\cdots+x_n=k$.  
2. Same as distributing $k$ identical items into $n$ distinct bins.  
3. Order of selection does not matter; types are distinct.  
4. Generating function $(1-x)^{-n}$.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Using $\binom{n}{k}$ with repetition | Under-counts |
| Using $n^k$ for unordered | Over-counts order |
| Mixing “types” and “items” | $n$ types, $k$ draws |

---
