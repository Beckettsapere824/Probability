# M4.8 Logarithmic-Series Distribution / 对数级数分布

**Prerequisites / 前置**: [M0.5 Series](M0.5.md), [M3.9 MGF](M3.9.md)

---

## Content / 内容

The logarithmic-series distribution has PMF
p(x) = −p^x / [x ln(1−p)], x=1,2,… (0<p<1).
Normalisation follows from the series −ln(1−p)=Σ_{i=1}^∞ p^i / i. The moment generating function is
M(t)=ln(1−p e^t)/ln(1−p) for t < −ln p.
Moments are obtained by differentiating the MGF and evaluating at the origin; one should not attempt to memorise complicated closed forms. The recommended derivation path is: verify normalisation → write MGF → differentiate → set t=0. When interchanging expectation and infinite sums the absolute-convergence condition |p e^t|<1 must be respected.

对数级数分布 PMF 为
p(x) = −p^x / [x ln(1−p)]，x=1,2,…（0<p<1）。
归一化来自级数 −ln(1−p)=Σ_{i=1}^∞ p^i / i。矩母函数为
M(t)=ln(1−p e^t)/ln(1−p)，t < −ln p。
矩通过对 MGF 求导并在原点取值得到；不应试图背诵复杂的闭式。推荐推导路径：验证归一化 → 写 MGF → 求导 → 令 t=0。交换期望与无穷和时必须遵守绝对收敛条件 |p e^t|<1。

## Example / 例子

p=1/2. p(1)= −(1/2)/ln(1/2)=1/(2 ln 2). The series of probabilities sums to 1 by the log expansion.

p=1/2。p(1)= −(1/2)/ln(1/2)=1/(2 ln 2)。概率级数由对数展开和为 1。
