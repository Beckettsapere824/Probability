# M7.8 Circuit-Board Testing Workflow / 电路板检测综合

**Prerequisites / 前置**: [M1.4](M1.4.md), [M1.5](M1.5.md), [M4.5](M4.5.md)

**Source anchors**: defect prevalence; test sensitivity; waiting time for defectives.

---

## What problem are we solving? / 我们要解决什么问题？

Combine **total probability**, **Bayes**, and **waiting times** for defective boards in a production line with imperfect tests.

把全概率、贝叶斯与次品等待时间合在同一检测流程里。

---

## Step 1: Defect model / 第一步：缺陷模型

Prior $\Pr(D)=p$. Test: $\Pr(+\mid D)=s$ (sensitivity), $\Pr(+\mid D^{c})=f$ (false positive rate).

---

## Step 2: Posterior after a positive / 第二步：阳性后验

$$\Pr(D\mid +)=\frac{sp}{sp+f(1-p)}.$$

---

## Step 3: Waiting for defectives / 第三步：等待次品

If boards are i.i.d. defective with probability $p$, number of boards until $r$ defectives is negative binomial. Expectation $r/p$.

---

## Must-build intuitions / 必须建立的直觉

1. Screening workflow = prevalence × accuracy × sequential count.  
2. Bayes updates belief about a single board; NB counts many boards.  
3. False positives dominate when $p$ is small.  
4. Keep the layers separate: composition → test → schedule.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Treating sensitivity as $\Pr(D\mid +)$ | Base rate |
| Mixing with-replacement waiting with depleting lots | State the model |
| Ignoring test errors in the waiting layer | Decide if “detected” or “true” defect |

---
