# M3.7 Order Statistic: Maximum PMF / 次序统计量：最大值 PMF

**Prerequisites / 前置**: [M2.1 Sampling Models](M2.1.md), [M1.8 Random Variables, PMF, CDF](M1.8.md)

---

## Content / 内容

Draw n distinct numbers without replacement from {1,2,…,N}. Let Y be the maximum. Then Y = y if and only if y itself is selected and the remaining n−1 numbers are chosen from {1,…,y−1}. Consequently
P(Y = y) = C(y−1, n−1) / C(N, n) for y = n,…,N.

从 {1,2,…,N} 无放回抽取 n 个不同数。设 Y 为最大值。则 Y = y 当且仅当选中 y 且其余 n−1 个数来自 {1,…,y−1}。因此
P(Y = y) = C(y−1, n−1) / C(N, n)，y = n,…,N。

The lower end of the support is necessarily n. The same combinatorial reasoning yields the PMF of the minimum or of any order statistic. Always verify that the PMF sums to 1.

支撑的下端必然是 n。同一组合推理可得最小值或任意次序统计量的 PMF。始终检查 PMF 和为 1。

## Example / 例子

N = 5, n = 2. P(Y = 3) = C(2,1)/C(5,2) = 2/10 = 1/5.

N = 5，n = 2。P(Y = 3) = C(2,1)/C(5,2) = 2/10 = 1/5。

## Practice Problem / 练习题

From {1,…,10} draw 3 numbers without replacement. Write P(Y = 7) where Y is the maximum.

从 {1,…,10} 无放回抽 3 个数。写出最大值 Y = 7 的概率。

<details>
<summary>Solution sketch / 解答提示</summary>

C(6,2)/C(10,3) = 15/120 = 1/8.

C(6,2)/C(10,3) = 15/120 = 1/8。

</details>
