# M2.3 Stars and Bars: Non-negative Integer Solutions / stars-bars：非负整数解

**Prerequisites / 前置**: [M0.3 Factorials, Permutations, Combinations](M0.3.md)

---

## Content / 内容

The number of non-negative integer solutions of x_1 + … + x_r = n is C(n + r - 1, r - 1). The same count enumerates the ways to place n indistinguishable balls into r distinguishable boxes (empty boxes allowed).

x_1 + … + x_r = n 的非负整数解个数为 C(n + r - 1, r - 1)。同一计数也枚举把 n 个不可区分球放入 r 个可区分盒子（允许空盒）的方式。

Inequalities are converted to equations by introducing a non-negative slack variable. If variables must be positive, first substitute y_i = x_i - 1. The range of summation is determined by the number of variables.

不等式通过引入非负松弛变量转为等式。若变量须为正，先令 y_i = x_i - 1。求和范围由变量个数决定。

Always combine with the boundary convention C(n,k) = 0 when k is illegal.

始终与组合数边界约定联用。

## Example / 例子

Number of non-negative solutions of x + y + z = 5 is C(5+3-1,3-1) = C(7,2) = 21.

x + y + z = 5 的非负解个数为 C(5+3-1,3-1) = C(7,2) = 21。

## Practice Problem / 练习题

How many non-negative integer solutions does x_1 + x_2 + x_3 + x_4 = 10 have?

x_1 + x_2 + x_3 + x_4 = 10 有多少非负整数解？

<details>
<summary>Solution sketch / 解答提示</summary>

C(10+4-1,4-1) = C(13,3) = 286.

C(10+4-1,4-1) = C(13,3) = 286。

</details>
