# M0.8 Matrices and Linear Systems / 矩阵与线性方程组

**Prerequisites / 前置**: None

---

## Content / 内容

A two-state transition matrix is a 2×2 matrix whose rows each sum to 1. Matrix multiplication represents one-step state transitions: if π is a row vector of current probabilities, then π P is the distribution after one step.

二状态转移矩阵是行和为 1 的 2×2 矩阵。矩阵乘法表示一步状态转移：若 π 是当前概率行向量，则 π P 是一步后的分布。

The stationary distribution satisfies the linear system π P = π together with the normalization π_1 + π_2 = 1 and non-negativity. The same linear-algebraic framework produces absorption probabilities: one writes a first-step equation for each transient state and solves the resulting system.

平稳分布满足线性方程组 π P = π，加上归一化 π_1 + π_2 = 1 和非负。同一线性代数框架产生吸收概率：对每个暂态写首步方程并解所得方程组。

Always check that the solution components are non-negative and sum to one (or lie in [0,1] for absorption probabilities).

始终检查解的分量非负且和为 1（对吸收概率则落在 [0,1]）。

## Example / 例子

P = [[0.6, 0.4], [0.3, 0.7]]. Stationary equations: π_W = 0.6 π_W + 0.3 π_L, π_L = 0.4 π_W + 0.7 π_L, π_W + π_L = 1. Solving yields π_W = 3/7, π_L = 4/7.

P = [[0.6, 0.4], [0.3, 0.7]]。平稳方程：π_W = 0.6 π_W + 0.3 π_L，π_L = 0.4 π_W + 0.7 π_L，π_W + π_L = 1。解得 π_W = 3/7，π_L = 4/7。

## Practice Problem / 练习题

For the same matrix, compute the two-step transition matrix P^2 and the probability of being in state W after two steps starting from W.

对同一矩阵，计算两步转移矩阵 P^2 以及从 W 出发两步后仍在 W 的概率。

<details>
<summary>Solution sketch / 解答提示</summary>

P^2 = [[0.48, 0.52], [0.39, 0.61]]. Starting from W the probability of W after two steps is the (1,1) entry 0.48.

P^2 = [[0.48, 0.52], [0.39, 0.61]]。从 W 出发两步后在 W 的概率是 (1,1) 元 0.48。
