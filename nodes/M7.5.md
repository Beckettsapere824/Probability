# M7.5 Secretary Letter Problem / 秘书信件问题

**Prerequisites / 前置**: [M2.11 Derangements](M2.11.md), [M3.10 Indicator Variables](M3.10.md), [M4.6 Poisson](M4.6.md)

---

## Content / 内容

The number X of correctly placed letters in a random permutation of n letters satisfies
P(X=k)=C(n,k) D_{n−k}/n!,
where D_m is the derangement count. By the indicator representation X=Σ I_j one obtains E(X)=1 for every n. As n→∞ the distribution of X converges to Poisson(1), consistent with the constant mean. Distinguish carefully between the events “exactly k fixed points” and “at least k fixed points”.

n 封信随机排列中正确放置的信件数 X 满足
P(X=k)=C(n,k) D_{n−k}/n!，
其中 D_m 为错排数。由指示表示 X=Σ I_j 得对每个 n 都有 E(X)=1。n→∞ 时 X 的分布收敛到 Poisson(1)，与恒定均值一致。仔细区分“恰好 k 个不动点”与“至少 k 个不动点”。

## Example / 例子

n=3. P(X=0)=D_3/6=1/3, P(X=1)=C(3,1)D_2/6=1/2, P(X=3)=1/6. E(X)=1.

n=3。P(X=0)=1/3，P(X=1)=1/2，P(X=3)=1/6。E(X)=1。

## Practice Problem / 练习题

Compute P(X=2) for n=4.

计算 n=4 时 P(X=2)。

<details>
<summary>Solution sketch / 解答提示</summary>

C(4,2) D_2 / 24 = 6·1 / 24 = 1/4.

C(4,2) D_2 / 24 = 6·1 / 24 = 1/4。

</details>
