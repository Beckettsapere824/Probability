# M3.1a Linearity of Expectation Needs No Independence / 期望线性性无需独立

**Prerequisites / 前置**: [M3.1 Expectation Definition and Linearity](M3.1.md)

---

## Content / 内容

The identity E(aX + bY) = a E(X) + b E(Y) holds for every pair of random variables (with finite expectations); independence is never required. Only the product rule E(XY) = E(X)E(Y) needs independence (or at least uncorrelatedness).

恒等式 E(aX + bY) = a E(X) + b E(Y) 对任意一对（期望有限的）随机变量成立；永远不需要独立。只有乘积法则 E(XY) = E(X)E(Y) 才需要独立（或至少不相关）。

Indicator-variable arguments for expectation rely solely on linearity and therefore remain valid even when the indicators are dependent. The same remark applies to sums of order statistics and to linear cost transformations. Do not confuse “expectation adds” with “variance adds”.

指示变量法求期望只依赖线性性，因此即使指示变量相依仍然有效。次序统计量求和、成本线性变换同样如此。不要把“期望可加”与“方差可加”混淆。

## Example / 例子

Let I_j be the indicator that the j-th ball is red in a without-replacement draw. The I_j are dependent, yet E(Σ I_j) = Σ E(I_j) still equals the expected number of red balls.

设 I_j 为无放回抽取中第 j 个球为红的指示。I_j 相依，但 E(Σ I_j) = Σ E(I_j) 仍等于红球期望数。

## Practice Problem / 练习题

Why can one compute the expected number of fixed points in a random permutation by linearity even though the indicators are dependent?

为什么随机排列中不动点个数的期望可以用线性性计算，即使指示变量相依？

<details>
<summary>Solution sketch / 解答提示</summary>

E(Σ I_j) = Σ E(I_j) holds regardless of dependence. Each E(I_j) = 1/n, so the sum is 1.

E(Σ I_j) = Σ E(I_j) 无论是否相依都成立。每个 E(I_j) = 1/n，故和为 1。

</details>
