# M3.3 Variance, Standard Deviation and E(X^2)−μ^2 / 方差、标准差与 E(X^2)−μ^2

**Prerequisites / 前置**: [M3.1 Expectation](M3.1.md), [M3.2 LOTUS](M3.2.md)

---

## Content / 内容

Variance is defined by Var(X) = E[(X − μ)^2] = E(X^2) − μ^2 where μ = E(X). The standard deviation is the non-negative square root σ = √Var(X). For a table distribution one first computes E(X^2) via LOTUS, then subtracts the square of the mean.

方差定义为 Var(X) = E[(X − μ)^2] = E(X^2) − μ^2，其中 μ = E(X)。标准差是非负平方根 σ = √Var(X)。表格分布先用 LOTUS 算 E(X^2)，再减去均值的平方。

The scaling rule is Var(aX + b) = a^2 Var(X). Variance is always non-negative; a negative numerical result signals an arithmetic error. The standard deviation carries the same physical unit as the original variable.

缩放法则：Var(aX + b) = a^2 Var(X)。方差永远非负；出现负数说明计算错误。标准差与原变量同单位。

## Example / 例子

X takes −1,0,1 with probabilities 1/4,1/2,1/4. μ = 0, E(X^2) = 1/2, Var(X) = 1/2, σ = √(1/2).

X 取值 −1,0,1，概率 1/4,1/2,1/4。μ = 0，E(X^2) = 1/2，Var(X) = 1/2，σ = √(1/2)。

## Practice Problem / 练习题

X has E(X) = 3 and E(X^2) = 13. Find Var(X) and σ.

X 满足 E(X) = 3，E(X^2) = 13。求 Var(X) 与 σ。

<details>
<summary>Solution sketch / 解答提示</summary>

Var(X) = 13 − 9 = 4，σ = 2。

Var(X) = 13 − 9 = 4，σ = 2。

</details>
