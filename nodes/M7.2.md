# M7.2 Prize PMF from Ball Draws / 抽球奖金分布

**Prerequisites / 前置**: [M1.8](M1.8.md), [M4.7](M4.7.md)

**Source anchors**: map outcomes to money; support of prize random variable; CDF from PMF.

---

## What problem are we solving? / 我们要解决什么问题？

Draws from an urn determine a monetary prize. List possible prize values, assign probabilities, then form PMF and CDF.

抽球结果映射为奖金：列出取值、概率，再写 PMF 与 CDF。

---

## Step 1: Define the map / 第一步：定义映射

Example: 3 red, 2 blue; draw 2 without replacement. Prize $=10$ if 2 red, $5$ if 1 red, $0$ if 0 red. Compute hypergeometric probabilities for each count of red.

---

## Step 2: PMF and CDF / 第二步：PMF 与 CDF

$p(v)=\Pr(\text{prize}=v)$ on the finite support. $F(x)=\sum_{v\le x}p(v)$.

---

## Step 3: Hand check / 第三步：手算

$\binom{5}{2}=10$ total. $\Pr(2\text{ red})=\binom{3}{2}\binom{2}{0}/10=3/10$ ⇒ $p(10)=0.3$.

---

## Must-build intuitions / 必须建立的直觉

1. Prize is a function of the draw — discrete RV.  
2. Different draws can map to the same prize (group before assigning $p$).  
3. Normalise over the prize support, not over raw sequences if unordered model is used.  
4. CDF jumps only at attainable prize values.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Using ordered counts when model is unordered | Match sampling model |
| Forgetting some prize values have probability 0 | List support carefully |
| CDF without sorting support | Order values ascending |

---
