## Content / 内容

### Definition 5.1 (absolute continuous type)

A random variable \(X\) is of the **(absolute) continuous type** if its cdf has the form

\[
F(x) = \Pr(X \le x) = \int_{-\infty}^{x} f(t)\,dt, \qquad -\infty < x < \infty,
\]

for some function \(f: \mathbb{R} \to [0,\infty)\). The function \(f\) is the **probability density function (pdf)**.

若随机变量 \(X\) 的分布函数可写成上式，则称 \(X\) 为（绝对）连续型；\(f\) 称为**概率密度函数 (pdf)**。连续型不再用 \(p(x)=\Pr(X=x)\) 描述概率行为。

### Properties of a pdf / pdf 的性质

1. If \(F\) is differentiable, then
   \[
   f(x) = \lim_{t \to 0} \frac{\Pr(X \le x+t) - \Pr(X \le x)}{t} = F'(x).
   \]
2. \(f(x) \ge 0\) for all \(x\).
3. \(\displaystyle\int_{-\infty}^{\infty} f(x)\,dx = F(\infty) = 1\).
4. \(\Pr(X \in A) = \displaystyle\int_A f(x)\,dx\) for any (measurable) \(A \subset \mathbb{R}\).
5. For continuous \(X\):
   - (a) \(\Pr(X=a) = 0\) for every \(a\);
   - (b) interval probabilities ignore endpoints:
     \[
     \Pr(a \le X \le b) = \Pr(a < X < b) = \int_a^b f(x)\,dx = F(b)-F(a);
     \]
   - (c) \(F\) is continuous everywhere.

### Mean, variance, MGF (Definition 5.2)

\[
\mu = E(X) = \int_{-\infty}^{\infty} x f(x)\,dx, \qquad
\sigma^2 = \mathrm{Var}(X) = E[(X-\mu)^2] = E(X^2)-\mu^2,
\]
\[
M_X(t) = E(e^{tX}) = \int_{-\infty}^{\infty} e^{tx} f(x)\,dx, \qquad
E(X^r) = M_X^{(r)}(0)
\]
(when the integral exists). Cumulant generating function \(R_X(t)=\ln M_X(t)\) gives \(\mu=R_X'(0)\), \(\sigma^2=R_X''(0)\).

## Example / 例子

**Example 5.1 (normalize a pdf).**  
\[
f(x) = \begin{cases} c(2x-x^2) & 0<x<2 \\ 0 & \text{otherwise.} \end{cases}
\]
Normalize:
\[
\int_0^2 c(2x-x^2)\,dx = c\Bigl[x^2 - \frac{x^3}{3}\Bigr]_0^2 = c\cdot\frac{4}{3} = 1 \implies c = \frac{3}{4}.
\]

**Example 5.2 (MGF → mean, variance).**  
\(f(x)=xe^{-x}\) for \(x>0\). Then
\[
M_X(t)=\int_0^\infty e^{tx} x e^{-x}\,dx = (1-t)^{-2}, \quad t<1,
\]
\(R_X(t)=-2\ln(1-t)\), so \(\mu=R'(0)=2\), \(\sigma^2=R''(0)=2\).

---

## Common pitfalls / 易错点

- Continuous \(\Pr(X=a)=0\); do **not** treat pdf height as a probability.
- Endpoints never matter for continuous interval probabilities.
- Always check \(\int f=1\) before computing means.

## Practice Problem / 练习题

Let
\[
f(x)=\begin{cases} kx(1-x) & 0<x<1 \\ 0 & \text{otherwise.} \end{cases}
\]
Find \(k\), \(F(x)\) on \((0,1)\), and \(\Pr(0.2<X<0.5)\).

<details>
<summary>Solution sketch / 解答提示</summary>

\(\int_0^1 kx(1-x)\,dx = k/6 = 1 \Rightarrow k=6\).  
\(F(x)=\int_0^x 6t(1-t)\,dt = 3x^2-2x^3\) for \(0<x<1\).  
\(\Pr(0.2<X<0.5)=F(0.5)-F(0.2)=0.5-0.104=0.396\).

</details>
