# M8.7 Chi-squared, t, F (index) / 卡方、t、F 索引

## What problem are we solving? / 我们要解决什么问题？

Name the standard **sampling distributions** built from i.i.d. normals, used in later inference. Exact densities are secondary; means, dfs, and table use come first.

从正态样本构造的抽样分布名称与自由度；密度细节次要，表与期望优先。

---

## Step 1: Chi-squared / 第一步：卡方

If $Z_i$ i.i.d. $N(0,1)$, then $\sum_{i=1}^{r}Z_i^{2}\sim\chi^{2}(r)$.  
$E(\chi^{2}(r))=r$, $\mathrm{Var}=2r$.

---

## Step 2: Student t / 第二步：t

$$t_r=\frac{Z}{\sqrt{V/r}},\quad Z\sim N(0,1),\ V\sim\chi^{2}(r)\ \text{independent}.$$

Heavier tails than normal; as $r\to\infty$, approaches $N(0,1)$.

---

## Step 3: F / 第三步：F

$$F_{d_1,d_2}=\frac{V_1/d_1}{V_2/d_2},\quad V_i\sim\chi^{2}(d_i)\ \text{independent}.$$

---

## Must-build intuitions / 必须建立的直觉

1. These laws are derived from normals, not arbitrary.  
2. Degrees of freedom count independent squared normals (roughly).  
3. Tables give quantiles for fixed df.  
4. t and F arise when σ is estimated, not known.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Using $z$ critical values when σ estimated | Use $t$ |
| $E(\chi^{2}(r))=2r$ | Mean is $r$, variance $2r$ |
| Forgetting independence of numerator/denominator in $t,F$ | Model assumptions |
