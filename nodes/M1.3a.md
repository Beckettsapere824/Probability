# M1.3a Conditional Complement and Conditional Independence / 条件补事件与条件独立

**Prerequisites / 前置**: [M1.2 Complement, Union, Inclusion-Exclusion](M1.2.md), [M1.3 Conditional Probability and Multiplication Rule](M1.3.md)

---

## Content / 内容

Under a fixed conditioning event the ordinary complement rule still holds: P(A^c|B) = 1 - P(A|B). Consequently if P(B'|D') = θ then P(B|D') = 1 - θ.

在固定条件事件下普通补事件公式仍然成立：P(A^c|B) = 1 - P(A|B)。因此若 P(B'|D') = θ，则 P(B|D') = 1 - θ。

Two events A and B are conditionally independent given C when P(A ∩ B|C) = P(A|C) P(B|C). Conditional independence is distinct from ordinary independence; one does not imply the other in general, and they cannot be interchanged freely.

两事件 A 与 B 在给定 C 时条件独立，当且仅当 P(A ∩ B|C) = P(A|C) P(B|C)。条件独立与普通独立不同；一般互不蕴含，不能随意互换。

All the usual rules (complement, union, inclusion-exclusion) remain valid when every probability is replaced by its conditional version given the same event.

所有常规法则（补、并、包含排除）在把每个概率换成同一事件下的条件版本后仍然有效。

## Example / 例子

In a diagnostic setting P(+|D) = 0.9, so P(-|D) = 0.1. If P(+|D^c) = θ then P(-|D^c) = 1 - θ.

诊断设定中 P(+|D) = 0.9，故 P(-|D) = 0.1。若 P(+|D^c) = θ，则 P(-|D^c) = 1 - θ。

## Practice Problem / 练习题

Show that if A and B are independent then A and B^c are also independent. Is the same true for conditional independence given C?

证明若 A 与 B 独立，则 A 与 B^c 也独立。对给定 C 的条件独立是否同样成立？

<details>
<summary>Solution sketch / 解答提示</summary>

P(A ∩ B^c) = P(A) - P(A ∩ B) = P(A) - P(A)P(B) = P(A)(1-P(B)) = P(A)P(B^c). The identical algebra works with every probability conditioned on C.

P(A ∩ B^c) = P(A) - P(A ∩ B) = P(A) - P(A)P(B) = P(A)(1-P(B)) = P(A)P(B^c)。把每个概率都换成条件于 C 的版本，同一代数成立。

</details>
