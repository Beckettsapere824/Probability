# M3.10 Indicator Variables and Linearity of Expectation / 指示变量与期望线性

**Prerequisites / 前置**: [M3.1 Expectation](M3.1.md), [M1.8 Random Variables, PMF, CDF](M1.8.md)

---

## Content / 内容

The indicator I_A of an event A satisfies E(I_A) = P(A). Any counting random variable can be written as a sum of indicators. Linearity then yields the expectation even when the indicators are highly dependent. The classic illustration is the number of fixed points in a random permutation: E(X) = Σ 1/n = 1.

事件 A 的指示 I_A 满足 E(I_A) = P(A)。任何计数随机变量都可写成指示之和。线性性即使在指示高度相依时仍给出期望。经典例子是随机排列的不动点数：E(X) = Σ 1/n = 1。

Variance calculations do require covariances (or independence). Indicator methods are ideal for “exactly k” or “at least one” counting problems.

求方差时才需要协方差（或独立）。指示变量法适合“恰好 k”或“至少一个”的计数问题。

## Example / 例子

In the secretary problem the number of correctly placed letters is X = Σ I_j with E(I_j) = 1/n, hence E(X) = 1.

秘书问题中正确放置的信件数 X = Σ I_j，E(I_j) = 1/n，故 E(X) = 1。

## Practice Problem / 练习题

n balls are thrown independently into n boxes. Let X be the number of empty boxes. Express X with indicators and find E(X).

n 个球独立投入 n 个盒子。设 X 为空盒数。用指示表达 X 并求 E(X)。

<details>
<summary>Solution sketch / 解答提示</summary>

I_j = 1 if box j empty. P(I_j=1) = ((n−1)/n)^n. E(X) = n ((n−1)/n)^n.

I_j = 1 若第 j 盒空。P(I_j=1) = ((n−1)/n)^n。E(X) = n ((n−1)/n)^n。

</details>
