# M0.7 Absolute Values, Inequalities, Linear Constraints / 绝对值、不等式与线性约束

**Prerequisites / 前置**: None

---

## Content / 内容

The event |X - μ| ≤ 2σ is the closed interval [μ - 2σ, μ + 2σ]. When X is discrete one simply sums the probability mass that falls inside the interval; endpoints must be checked for inclusion.

事件 |X - μ| ≤ 2σ 就是闭区间 [μ - 2σ, μ + 2σ]。X 离散时直接累加落在区间内的概率质量；端点是否包含要检查。

Logarithmic inequalities of the form a^n < b are converted by taking natural logs: n ln a < ln b. When 0 < a < 1 the logarithm is negative and the inequality direction reverses upon division.

形如 a^n < b 的对数不等式取自然对数后变成 n ln a < ln b。当 0 < a < 1 时对数为负，除以它时不等号方向反向。

Probability upper-bound problems produce linear inequalities on parameters together with non-negativity constraints. The feasible region is a polyhedron; the optimum of a linear objective occurs at a vertex. Always verify that candidate points satisfy every constraint.

概率上界问题产生参数的线性不等式以及非负约束。可行域是多面体；线性目标的最优值在顶点取得。始终验证候选点满足所有约束。

Absolute-value equations or inequalities are solved by splitting into cases according to the sign of the expression inside the absolute value.

绝对值方程或不等式按绝对值内部表达式的正负分情况讨论。

## Example / 例子

Solve (0.9)^n < 0.5. ln(0.9)^n < ln 0.5 ⇒ n ln 0.9 < ln 0.5. Divide by negative number: n > ln 0.5 / ln 0.9 ≈ 6.58, so n ≥ 7.

解 (0.9)^n < 0.5。ln(0.9)^n < ln 0.5 ⇒ n ln 0.9 < ln 0.5。除以负数：n > ln 0.5 / ln 0.9 ≈ 6.58，故 n ≥ 7。

## Practice Problem / 练习题

Suppose 0 ≤ α ≤ 1, 0 ≤ β ≤ 1 and the inequalities α + β ≤ 1, 2α + β ≤ 1.5 hold. Maximize β. What is the maximum value and at which point is it attained?

设 0 ≤ α ≤ 1，0 ≤ β ≤ 1，且满足 α + β ≤ 1，2α + β ≤ 1.5。最大化 β。最大值是多少，在哪个点取得？

<details>
<summary>Solution sketch / 解答提示</summary>

The binding constraints at the optimum are α + β = 1 and β ≤ 1; the point (0,1) satisfies 2α + β = 1 ≤ 1.5. Maximum β = 1.

最优处紧约束为 α + β = 1 且 β ≤ 1；点 (0,1) 满足 2α + β = 1 ≤ 1.5。最大 β = 1。

</details>
