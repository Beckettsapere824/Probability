# M2.5 Upper Bounds and Inclusion-Exclusion / 上界约束与容斥

**Prerequisites / 前置**: [M2.3 Stars and Bars](M2.3.md), [M1.2 Complement, Union, Inclusion-Exclusion](M1.2.md)

---

## Content / 内容

Count the unrestricted solutions first, then subtract the cases in which one or more variables violate an upper bound. For the constraint x_i ≤ b_i the forbidden region is x_i ≥ b_i+1; the change of variable x_i' = x_i - (b_i+1) restores a non-negative equation.

先算无约束解，再减去一个或多个变量越上界的情形。对约束 x_i ≤ b_i，禁止区域为 x_i ≥ b_i+1；换元 x_i' = x_i - (b_i+1) 恢复非负方程。

Inclusion-exclusion then adds back the double violations, subtracts the triple violations, and so on. Before applying the machinery, check whether every upper bound already exceeds the total sum; if so the bounds are automatic and inclusion-exclusion is unnecessary.

容斥再加回两两越界、减去三重越界，依此类推。套用前先检查每个上界是否已大于总和；若是则上界自动满足，无需容斥。

## Example / 例子

x+y+z = 10, each ≤ 6. Unrestricted non-negative: C(12,2)=66. One variable ≥ 7: C(5,2)=10 per variable, three variables → 30. Two variables ≥ 7 impossible. Answer 66-30=36.

x+y+z = 10，每变量 ≤ 6。无约束非负：C(12,2)=66。一变量 ≥ 7：每变量 C(5,2)=10，共 30。两变量 ≥ 7 不可能。答案 66-30=36。

## Practice Problem / 练习题

Number of non-negative solutions of x+y+z = 15 with each variable at most 7.

x+y+z = 15 且每变量 ≤ 7 的非负解个数。

<details>
<summary>Solution sketch / 解答提示</summary>

Unrestricted C(17,2)=136. One ≥ 8: C(9,2)=36 per variable → 108. Two ≥ 8: remaining sum ≤ -1 impossible after substitution, or direct check shows remaining non-negative sum negative. Answer 136-108=28.

无约束 C(17,2)=136。一变量 ≥ 8：每变量 C(9,2)=36 → 108。两变量 ≥ 8：剩余和为负，不可能。答案 136-108=28。

</details>
