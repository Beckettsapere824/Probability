# M2.3a Condition Diagnosis for Integer Solutions / 整数解题的条件甄别

**Prerequisites / 前置**: [M2.3 Stars and Bars](M2.3.md), [M2.4 Positive Solutions](M2.4.md), [M2.5 Upper Bounds](M2.5.md)

---

## Content / 内容

Before applying any formula, confirm whether the variables are required to be non-negative integers, positive integers, unrestricted integers, or integers lying between explicit lower and upper bounds.

套用任何公式前，先确认变量是“非负整数”“正整数”“任意整数”还是“有上下界的整数”。

Non-negative solutions use C(n+r-1,r-1). Positive solutions are reduced to non-negative by y_i = x_i - 1. An inequality such as x+y+z < 25 becomes x+y+z ≤ 24 and then an equation with a slack variable.

非负解用 C(n+r-1,r-1)。正整数解令 y_i = x_i - 1 后转非负。不等式 x+y+z < 25 转为 x+y+z ≤ 24，再加松弛变量成等式。

If the sum is fixed and every upper bound is larger than the sum, the upper bounds are automatically satisfied and inclusion-exclusion is unnecessary. Only when an upper bound is smaller than the remaining sum does one need to subtract the violating cases. A problem that merely says “integer solutions” without the adjective “non-negative” cannot be assumed non-negative.

若和固定且每个上界都大于该和，则上界自动满足，无需容斥；仅当上界小于剩余和时才需减去越界情形。题干只写“integer solutions”而未写非负时，不能默认非负。

When an answer disagrees with a routine count, the first check is whether a non-negativity, positivity, upper-bound or inequality condition was missed.

答案与常规计数不符时，先回查是否漏了“非负/正/上界/不等式”条件。

## Example / 例子

x+y+z = 5, x,y,z ≥ 0 → C(7,2). Same equation with x,y,z ≥ 1 → C(4,2). Same equation with each ≤ 3: the unrestricted non-negative count already satisfies the bounds, so no further subtraction.

x+y+z = 5，x,y,z ≥ 0 → C(7,2)。同方程 x,y,z ≥ 1 → C(4,2)。同方程每变量 ≤ 3：无约束非负解已满足上界，无需再减。

## Practice Problem / 练习题

How many positive integer solutions does x+y+z = 10 have with each variable at most 6?

x+y+z = 10 有多少正整数解且每变量 ≤ 6？

<details>
<summary>Solution sketch / 解答提示</summary>

First ignore upper bounds: y_i = x_i-1 ≥ 0, y1+y2+y3 = 7 → C(9,2)=36. Cases with one variable ≥ 7: set that variable = 7+t, t≥0, then remaining sum = 3-t; only t=0 possible, 3 solutions per variable, 9 total. No two variables can both be ≥7. Answer 36-9=27.

先忽略上界：y_i=x_i-1≥0，和为7→C(9,2)=36。某变量≥7：设为7+t，剩余和3-t，仅t=0，每变量3解，共9。两变量不可能同时≥7。答案36-9=27。

</details>
