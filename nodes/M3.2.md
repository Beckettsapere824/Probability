# M3.2 Law of the Unconscious Statistician (LOTUS) / 随机变量函数的期望 LOTUS

**Prerequisites / 前置**: [M3.1 Expectation Definition and Linearity](M3.1.md)

---

## Content / 内容

For a function g the expectation of the transformed random variable is obtained directly from the original distribution: E(g(X)) = Σ g(x) p(x). One need not first find the distribution of g(X) unless that distribution is required for other reasons.

对函数 g，变换后随机变量的期望直接由原分布得到：E(g(X)) = Σ g(x) p(x)。除非另有需要，不必先求 g(X) 的分布。

Typical calculations include E(X), E(X^2) and E(4X^2 − 2X + 3). Symmetry (for example support symmetric about zero) often simplifies the arithmetic. Linear combinations are handled by ordinary linearity rather than by LOTUS.

典型计算包括 E(X)、E(X^2) 与 E(4X^2 − 2X + 3)。对称性（例如支撑关于零对称）常可简化算术。线性组合用普通线性性处理，而非 LOTUS。

## Example / 例子

X takes −1,0,1 with equal probability 1/3. E(X^2) = 1·(1/3)+0+1·(1/3) = 2/3. E(X) = 0 by symmetry.

X 取值 −1,0,1，各概率 1/3。E(X^2) = 1·(1/3)+0+1·(1/3) = 2/3。E(X) = 0（对称）。

## Practice Problem / 练习题

X has PMF p(−2)=1/4, p(0)=1/2, p(2)=1/4. Compute E(X^2) and E(3X^2 − 1).

X 的 PMF 为 p(−2)=1/4, p(0)=1/2, p(2)=1/4。求 E(X^2) 与 E(3X^2 − 1)。

<details>
<summary>Solution sketch / 解答提示</summary>

E(X^2) = 4·(1/4)+0+4·(1/4) = 2. E(3X^2−1) = 3·2 − 1 = 5.

</details>
