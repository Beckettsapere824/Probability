# M1.1 Sample Space, Events, Probability Axioms / 样本空间、事件、概率公理

**Prerequisites / 前置**: [M0.1 Sets and Event Language](M0.1.md)

**Source anchors**: SDST2601A Ch3 §3.1.3 Def 3.1 (Kolmogorov); classical model as special case.

---

## What problem are we solving? / 我们要解决什么问题？

We want one mathematical language that works for dice, coins, continuous measurements, and infinite sequences of trials — without inventing a new rule each time.

我们要一套统一的数学语言，既能说骰子和硬币，也能说连续测量和无穷次试验——而不是每种情况另立规矩。

Kolmogorov’s answer (1933): fix a **sample space** of outcomes, call certain subsets **events**, and require a number $\Pr(E)$ on events to obey three axioms.

---

## Step 1: Sample space and events / 第一步：样本空间与事件

The **sample space** $\Omega$ is the set of all outcomes. An **event** is a subset $E\subseteq\Omega$ that you are allowed to assign probability to.

Examples: one die $\Omega=\{1,2,3,4,5,6\}$; two ordered coin flips $\Omega=\{\mathrm{HH},\mathrm{HT},\mathrm{TH},\mathrm{TT}\}$; continuous waiting time $\Omega=(0,\infty)$.

**Choosing $\Omega$ is modelling.** Listing two coins as $\{\text{0 heads},\text{1 head},\text{2 heads}\}$ hides that “1 head” arises in two ways.

---

## Step 2: Kolmogorov’s three axioms / 第二步：三条公理

1. **Non-negativity:** $\Pr(E)\ge 0$.  
2. **Normalization:** $\Pr(\Omega)=1$.  
3. **Countable additivity:** pairwise disjoint $E_i$ ⇒ $\Pr(\bigcup E_i)=\sum\Pr(E_i)$.

Consequences: $\Pr(\emptyset)=0$; $\Pr(E^{c})=1-\Pr(E)$; monotonicity $A\subset B\implies\Pr(A)\le\Pr(B)$.

---

## Step 3: Classical (equally likely) model / 第三步：古典概型

When $\Omega$ is finite and every outcome is equally likely, $\Pr(A)=|A|/|\Omega|$. This is a special case of the axioms, not the definition of probability.

---

## Step 4: Hand checks / 第四步：手算

Disjoint union on a die: $A=\{1,3\}$, $B=\{2,4\}$ ⇒ $\Pr(A\cup B)=4/6=\Pr(A)+\Pr(B)$.  
Two coins: $\Pr(\text{at least one head})=3/4$.

---

## Must-build intuitions / 必须建立的直觉

1. Probability is a set function obeying three axioms.  
2. Sample space choice is part of the model.  
3. Countable additivity is the infinite version of adding disjoint pieces.  
4. Classical counting is a special case, not the foundation.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Any verbal description treated as equally likely $\Omega$ | Check symmetry |
| $|A|/|\Omega|$ when outcomes not equally likely | Use weighted models |
| Additivity on overlapping events | Only for disjoint unions |
| Forgetting $\Pr(\Omega)=1$ | Always normalise |
