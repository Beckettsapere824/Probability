# M1.1 Sample Space, Events, Probability Axioms / 样本空间、事件、概率公理

**Prerequisites / 前置**: [M0.1 Sets and Event Language](M0.1.md)

**Source / 来源**: SDST2601A Chapter 3 §3.1.3 Definition 3.1 (Kolmogorov)

---

## What problem are we solving? / 我们要解决什么问题？

We want a single mathematical language that works for dice, coins, continuous measurements, and infinite sequences of trials—without inventing a new rule each time.

我们要一套统一的数学语言，既能说骰子和硬币，也能说连续测量和无穷次试验——而不是每种情况另立规矩。

Kolmogorov’s answer (1933): fix a **sample space** of outcomes, call certain subsets **events**, and require a number $\Pr(E)$ on events to obey three axioms.

Kolmogorov（1933）的答案：固定结果的**样本空间**，把某些子集叫做**事件**，要求事件上的数 $\Pr(E)$ 满足三条公理。

---

## Step 1: Sample space and events / 第一步：样本空间与事件

The **sample space** $\Omega$ is the set of all outcomes of the experiment you care about. An **event** is a subset $E\subseteq\Omega$ that you are allowed to assign probability to.

**样本空间** $\Omega$ 是你关心的试验的全部结果。**事件**是你允许赋予概率的子集 $E\subseteq\Omega$。

Examples: one die $\Omega=\{1,2,3,4,5,6\}$; two ordered coin flips $\Omega=\{(H,H),(H,T),(T,H),(T,T)\}$.

例：一颗骰子；$\Omega=\{1,2,3,4,5,6\}$；两次有序抛币如上。

---

## Step 2: Kolmogorov’s three axioms (Def 3.1) / 第二步：三条公理

A probability on $\Omega$ assigns to each event $E$ a number $\Pr(E)$ such that:

1. **Non-negativity:** $\Pr(E)\ge 0$ for every event $E$.  
2. **Normalization:** $\Pr(\Omega)=1$.  
3. **Countable additivity:** if $E_1,E_2,\ldots$ are pairwise disjoint ($E_i\cap E_j=\emptyset$ for $i\neq j$), then
   $$\Pr\Bigl(\bigcup_{i=1}^{\infty} E_i\Bigr)=\sum_{i=1}^{\infty}\Pr(E_i).$$

From these one gets $\Pr(\emptyset)=0$, finite additivity for disjoint unions, and $\Pr(E^{c})=1-\Pr(E)$.

由此得到 $\Pr(\emptyset)=0$、有限可加性，以及 $\Pr(E^{c})=1-\Pr(E)$。

---

## Step 3: Classical model as a special case / 第三步：古典概型是特例

When $\Omega$ is finite and every outcome is equally likely,

$$\Pr(A)=\frac{|A|}{|\Omega|}.$$

This satisfies the axioms, but only after you have chosen an $\Omega$ in which “equally likely” is honest (e.g. ordered pairs for two coins, not “number of heads”).

这满足公理，但前提是 $\Omega$ 选得使「等可能」站得住（例如两次抛币用有序对，而不是「正面次数」）。

---

## Step 4: Hand check (Example 3.2 style) / 第四步：手算核对

$\Omega=\{1,2,3,4,5,6\}$, $A=\{1,3\}$, $B=\{2,4\}$ (disjoint).

$\Pr(A)=2/6$, $\Pr(B)=2/6$, $\Pr(A\cup B)=4/6=\Pr(A)+\Pr(B)$ — axiom 3 on two events.

---

## Summary / 小结

- Probability is not “the fraction of times” until you add a model; the axioms are the model’s rules.  
- Classical counting is one model among others, not the definition of probability.

---

## Common pitfalls / 易错点

- Treating any verbal description as an equally likely $\Omega$ without checking symmetry.  
- Applying $|A|/|\Omega|$ when outcomes are not equally likely.  
- Forgetting that axiom 3 is about **disjoint** unions.

---

## Practice / 练习

Fair coin tossed twice. List $\Omega$. Let $A=$“at least one head”, $B=$“two heads”. Find $\Pr(A)$, $\Pr(B)$, $\Pr(A\cap B)$, $\Pr(A\cup B)$.

<details>
<summary>Solution sketch / 解答提示</summary>

$\Omega=\{HH,HT,TH,TT\}$, each $1/4$.  
$A=\{HH,HT,TH\}$, $\Pr(A)=3/4$. $B=\{HH\}$, $\Pr(B)=1/4$.  
$A\cap B=B$, $\Pr=1/4$. $A\cup B=A$, $\Pr=3/4$.

</details>
