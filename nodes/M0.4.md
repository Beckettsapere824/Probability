# M0.4 Binomial Coefficient Identities / 二项式系数恒等式

**Prerequisites / 前置**: [M0.3 Factorials, Permutations, Combinations](M0.3.md)

---

## Content / 内容

Pascal’s identity: C(n,k) = C(n-1,k-1) + C(n-1,k). It follows from partitioning the k-subsets according to whether a fixed element is included.

Pascal 恒等式：C(n,k) = C(n-1,k-1) + C(n-1,k)。把 k 元子集按是否包含某个固定元素分成两类即可。

Hockey-stick identity: Σ_{k=r}^m C(k,r) = C(m+1,r+1). The sum of binomial coefficients with fixed lower index r starting from k = r up to m equals a single larger binomial coefficient.

Hockey-stick 恒等式：Σ_{k=r}^m C(k,r) = C(m+1,r+1)。固定下标 r、从 k = r 加到 m 的组合数之和等于一个更大的组合数。

Another useful relation: C(n,k)/(k+1) = C(n+1,k+1)/(n+1). It converts a sum involving 1/(k+1) into an ordinary binomial sum.

另一个常用关系：C(n,k)/(k+1) = C(n+1,k+1)/(n+1)。它把含 1/(k+1) 的和变成普通二项式和。

These identities simplify combinatorial sums that appear in expectations of reciprocal functions, coefficient extraction, and order-statistic calculations.

这些恒等式用于化简倒数期望、系数提取和次序统计量计算中出现的组合求和。

## Example / 例子

Σ_{k=4}^{10} C(k,4) = C(11,5) by hockey-stick. Direct computation of the left side is tedious; the right side is a single number.

Σ_{k=4}^{10} C(k,4) = C(11,5)（hockey-stick）。左边直接算很繁琐，右边是一个数。

## Practice Problem / 练习题

Prove (or verify for small n) that Σ_{k=0}^n C(n,k)/(k+1) = (2^{n+1}-1)/(n+1). Hint: use the identity above and the binomial theorem.

证明（或对小 n 验证）Σ_{k=0}^n C(n,k)/(k+1) = (2^{n+1}-1)/(n+1)。提示：用上面的恒等式和二项式定理。

<details>
<summary>Solution sketch / 解答提示</summary>

C(n,k)/(k+1) = C(n+1,k+1)/(n+1). Sum becomes (1/(n+1)) Σ C(n+1,k+1) = (1/(n+1)) Σ_{j=1}^{n+1} C(n+1,j) = (2^{n+1}-1)/(n+1).

C(n,k)/(k+1) = C(n+1,k+1)/(n+1)。求和变成 (1/(n+1)) Σ C(n+1,k+1) = (1/(n+1)) Σ_{j=1}^{n+1} C(n+1,j) = (2^{n+1}-1)/(n+1)。

</details>
