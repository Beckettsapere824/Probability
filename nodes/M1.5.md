# M1.5 Bayes’ Theorem / 贝叶斯公式

**Prerequisites / 前置**: [M1.3 Conditional Probability and Multiplication Rule](M1.3.md), [M1.4 Law of Total Probability](M1.4.md)

---

## Content / 内容

Bayes’ theorem states
P(A_i|B) = P(B|A_i) P(A_i) / Σ_j P(B|A_j) P(A_j).
The numerator is prior times likelihood; the denominator is the marginal probability of the data (total probability). The result is the posterior probability.

贝叶斯定理：
P(A_i|B) = P(B|A_i) P(A_i) / Σ_j P(B|A_j) P(A_j)。
分子是先验乘似然；分母是数据的边际概率（全概率）。结果是后验概率。

When a threshold parameter must be solved for, write the posterior as a fractional equation in that parameter and clear the denominator. Base-rate neglect is the common intuition error: when the prior is very small the posterior can remain modest even if the test is accurate.

需要反解阈值参数时，把后验写成该参数的分式方程再去分母。基础率谬误是常见直觉错误：先验很小时，即使检测准确，后验仍可能不高。

## Example / 例子

Using the numbers of the previous node: P(D|+) = (0.95·0.01) / 0.1085 ≈ 0.0876. Only about 9 % of positive tests correspond to true disease.

用上一节点的数字：P(D|+) = (0.95·0.01) / 0.1085 ≈ 0.0876。阳性检测中只有约 9 % 真正患病。

## Practice Problem / 练习题

Sensitivity 0.99, specificity 0.99, prevalence θ. Find the smallest θ such that P(D|+) ≥ 0.5.

敏感度 0.99、特异度 0.99、患病率 θ。求使 P(D|+) ≥ 0.5 的最小 θ。

<details>
<summary>Solution sketch / 解答提示</summary>

P(D|+) = 0.99θ / (0.99θ + 0.01(1-θ)) ≥ 1/2 ⇒ 0.99θ ≥ 0.01 - 0.01θ ⇒ 1.0θ ≥ 0.01 ⇒ θ ≥ 0.01.

P(D|+) = 0.99θ / (0.99θ + 0.01(1-θ)) ≥ 1/2 ⇒ 0.99θ ≥ 0.01 - 0.01θ ⇒ θ ≥ 0.01。

</details>
