# M1.3 Conditional Probability and Multiplication Rule / 条件概率与乘法公式

**Prerequisites / 前置**: [M1.1 Sample Space, Events, Probability Axioms](M1.1.md)

---

## Content / 内容

Conditional probability is defined by P(A|B) = P(A ∩ B) / P(B) whenever P(B) > 0. The denominator is the conditioning event, not the whole sample space. The multiplication rule rearranges the definition: P(A ∩ B) = P(A|B) P(B) = P(B|A) P(A).

条件概率定义为 P(A|B) = P(A ∩ B) / P(B)（P(B) > 0）。分母是条件事件，不是全集。乘法公式是定义的重排：P(A ∩ B) = P(A|B) P(B) = P(B|A) P(A)。

Conditional probability itself satisfies the probability axioms on the restricted space. For three or more events the chain rule reads P(A ∩ B ∩ C) = P(A) P(B|A) P(C|A ∩ B).

条件概率本身在受限空间上满足概率公理。对三个及以上事件，链式法则为 P(A ∩ B ∩ C) = P(A) P(B|A) P(C|A ∩ B)。

## Example / 例子

A fair die is rolled. Let A = “even”, B = “greater than 3”. Then P(A|B) = P({4,6}) / P({4,5,6}) = 2/3.

公平骰子。设 A = “偶数”，B = “大于 3”。则 P(A|B) = P({4,6}) / P({4,5,6}) = 2/3。

## Practice Problem / 练习题

Two cards are drawn without replacement from a standard deck. Find the probability that both are aces, and the probability that the second is an ace given that the first was an ace.

从标准牌组无放回抽两张。求两张都是 A 的概率，以及第一张是 A 的条件下第二张也是 A 的概率。

<details>
<summary>Solution sketch / 解答提示</summary>

P(both aces) = (4/52)·(3/51). P(second ace | first ace) = 3/51.

P(两张 A) = (4/52)·(3/51)。P(第二张 A | 第一张 A) = 3/51。

</details>
