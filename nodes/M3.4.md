# M3.4 Expectation and Variance of Linear Transformations / 线性变换的期望与方差

**Prerequisites / 前置**: [M3.1 Expectation](M3.1.md), [M3.3 Variance](M3.3.md)

---

## Content / 内容

If Y = aX + b then E(Y) = a E(X) + b, Var(Y) = a^2 Var(X) and sd(Y) = |a| sd(X). The absolute value appears because standard deviation is non-negative. Linear transformations merely shift and scale the distribution; they do not change its shape.

若 Y = aX + b，则 E(Y) = a E(X) + b，Var(Y) = a^2 Var(X)，sd(Y) = |a| sd(X)。绝对值出现是因为标准差非负。线性变换只平移与缩放分布，不改变其形状。

A typical application is a cost function C = 13000 + 2000 X where X is a lifetime measured in years. First compute the moments of X, then apply the linear rules.

典型应用是成本函数 C = 13000 + 2000 X，其中 X 为以年为单位的寿命。先算 X 的矩，再套用线性法则。

## Example / 例子

E(X) = 5, Var(X) = 4. For C = 100 + 3X one has E(C) = 115, Var(C) = 36, sd(C) = 6.

E(X) = 5，Var(X) = 4。对 C = 100 + 3X 有 E(C) = 115，Var(C) = 36，sd(C) = 6。

## Practice Problem / 练习题

X has mean 10 and standard deviation 2. Let Y = 50 − 4X. Find E(Y) and sd(Y).

X 均值 10、标准差 2。设 Y = 50 − 4X。求 E(Y) 与 sd(Y)。

<details>
<summary>Solution sketch / 解答提示</summary>

E(Y) = 50 − 4·10 = 10。sd(Y) = |−4|·2 = 8。

E(Y) = 50 − 4·10 = 10。sd(Y) = |−4|·2 = 8。

</details>
