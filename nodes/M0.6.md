# M0.6 Derivatives and Taylor / MGF Differentiation / 导数与泰勒/MGF 求导

**Prerequisites / 前置**: [M0.5 Sums, Series, Logarithmic Expansion](M0.5.md)

---

## Content / 内容

Moment-generating functions are differentiated with respect to the parameter t and then evaluated at t = 0. The r-th derivative satisfies M_X^{(r)}(0) = E(X^r). In particular M'(0) = E(X) and M''(0) = E(X^2).

矩母函数对参数 t 求导后在 t = 0 处取值。第 r 阶导数满足 M_X^{(r)}(0) = E(X^r)。特别地 M'(0) = E(X)，M''(0) = E(X^2)。

Composite-function differentiation is required for expressions such as d/dt ln(1 - p e^t) = -p e^t / (1 - p e^t). The radius of convergence of an MGF is found by solving the inequality that makes the series absolutely convergent (e.g. |p e^t| < 1).

复合函数求导对形如 d/dt ln(1 - p e^t) = -p e^t / (1 - p e^t) 的表达式是必需的。MGF 的收敛域通过解使级数绝对收敛的不等式得到（例如 |p e^t| < 1）。

Once the first two derivatives at zero are known, variance follows immediately: Var(X) = M''(0) - [M'(0)]^2.

已知零点处的前两阶导数后，方差立即得出：Var(X) = M''(0) - [M'(0)]^2。

## Example / 例子

For the geometric MGF M(t) = p e^t / (1 - (1-p) e^t) (t < -ln(1-p)), differentiate and set t = 0 to recover E(T) = 1/p and Var(T) = (1-p)/p^2.

几何分布 MGF M(t) = p e^t / (1 - (1-p) e^t)（t < -ln(1-p)），求导并令 t = 0 即得 E(T) = 1/p，Var(T) = (1-p)/p^2。

## Practice Problem / 练习题

Let M(t) = ln(1 - p e^t) / ln(1-p) for t < -ln p. Compute M'(0) and M''(0). (This is the MGF of the logarithmic-series distribution.)

设 M(t) = ln(1 - p e^t) / ln(1-p)，t < -ln p。计算 M'(0) 和 M''(0)。（这是对数级数分布的 MGF。）

<details>
<summary>Solution sketch / 解答提示</summary>

Let c = 1/ln(1-p). M'(t) = c · (-p e^t)/(1 - p e^t). M'(0) = c · (-p)/(1-p). M''(t) requires quotient rule; evaluate at 0 to obtain E(X^2). Then variance = M''(0) - [M'(0)]^2.

令 c = 1/ln(1-p)。M'(t) = c · (-p e^t)/(1 - p e^t)。M'(0) = c · (-p)/(1-p)。M''(t) 用商法则；在 0 处取值得 E(X^2)。然后方差 = M''(0) - [M'(0)]^2。

</details>
