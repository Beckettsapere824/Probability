# M0.5 Sums, Series, Logarithmic Expansion / 求和、级数、对数展开

**Prerequisites / 前置**: [M0.3 Factorials, Permutations, Combinations](M0.3.md)

---

## Content / 内容

The infinite geometric series Σ_{k=0}^∞ r^k = 1/(1-r) for |r| < 1. Differentiating term by term yields Σ_{k=1}^∞ k r^{k-1} = 1/(1-r)^2, again for |r| < 1. These are the basic tools for summing geometric waiting-time probabilities.

无穷几何级数 Σ_{k=0}^∞ r^k = 1/(1-r)（|r| < 1）。逐项求导得 Σ_{k=1}^∞ k r^{k-1} = 1/(1-r)^2（同样 |r| < 1）。它们是几何等待时间概率求和的基本工具。

The logarithmic series -ln(1-a) = Σ_{i=1}^∞ a^i / i for -1 < a < 1 is the normalization identity for the logarithmic-series distribution and appears in moment-generating-function calculations.

对数级数 -ln(1-a) = Σ_{i=1}^∞ a^i / i（-1 < a < 1）是对数级数分布的归一化恒等式，也出现在矩母函数计算中。

When changing the order of summation, interchanging a sum with an expectation, or differentiating under a sum, first verify absolute convergence (or the relevant domination condition). Finite sums never need a convergence check; infinite sums always do.

换元求和、交换求和与期望、或在求和号下求导时，先检查绝对收敛（或相应控制条件）。有限和无需收敛检查；无限和必须写收敛条件。

## Example / 例子

Σ_{k=0}^∞ (1/2)^k = 2. Σ_{k=1}^∞ k (1/2)^{k-1} = 4. -ln(1-1/2) = ln 2 = Σ_{i=1}^∞ (1/2)^i / i.

Σ_{k=0}^∞ (1/2)^k = 2。Σ_{k=1}^∞ k (1/2)^{k-1} = 4。-ln(1-1/2) = ln 2 = Σ_{i=1}^∞ (1/2)^i / i。

## Practice Problem / 练习题

Show that Σ_{k=1}^∞ k r^k = r/(1-r)^2 for |r| < 1. (Start from the differentiated geometric series and multiply by r.)

证明对 |r| < 1 有 Σ_{k=1}^∞ k r^k = r/(1-r)^2。（从求导后的几何级数出发再乘以 r。）

<details>
<summary>Solution sketch / 解答提示</summary>

Σ k r^{k-1} = 1/(1-r)^2. Multiply both sides by r: Σ k r^k = r/(1-r)^2.

Σ k r^{k-1} = 1/(1-r)^2。两边乘 r：Σ k r^k = r/(1-r)^2。

</details>
