# M1.2a Probability Monotonicity, Inclusion and Upper Bounds / 概率单调性、包含关系与概率上界

**Prerequisites / 前置**: [M1.1 Sample Space, Events, Probability Axioms](M1.1.md), [M1.2 Complement, Union, Inclusion-Exclusion](M1.2.md)

---

## Content / 内容

If A ⊆ B then P(A) ≤ P(B). Consequently P(A ∩ B) ≤ min(P(A), P(B)). The probability of any union is at most 1, and every intersection probability is non-negative.

若 A ⊆ B 则 P(A) ≤ P(B)。因此 P(A ∩ B) ≤ min(P(A), P(B))。任意并的概率至多为 1，每个交概率非负。

These elementary inequalities turn inclusion-exclusion expressions into linear constraints on unknown parameters. The resulting feasible region can be used to find the largest admissible value of a parameter or to obtain sharp probability upper bounds.

这些初等不等式把包含排除表达式变成未知参数的线性约束。所得可行域可用于求参数的最大可行值或得到尖锐的概率上界。

Always verify non-negativity of all probabilities that appear and that the union probability never exceeds 1.

始终验证出现的所有概率非负，且并概率不超过 1。

## Example / 例子

Suppose P(A) = α, P(B) = α, P(C) = β, P(A ∩ B) = α/2, and all other pairwise and the triple intersections are zero. Then P(A ∪ B ∪ C) = 2α + β - α/2 ≤ 1, which forces a linear relation between α and β.

设 P(A) = α，P(B) = α，P(C) = β，P(A ∩ B) = α/2，其余两两交与三重交为零。则 P(A ∪ B ∪ C) = 2α + β - α/2 ≤ 1，从而得到 α 与 β 的线性关系。

## Practice Problem / 练习题

Events A, B, C satisfy P(A) = P(B) = P(C) = α, every pairwise intersection equals β, and the triple intersection equals γ. Write the three inequalities that follow from non-negativity of the inclusion-exclusion terms and from P(union) ≤ 1.

事件 A, B, C 满足 P(A) = P(B) = P(C) = α，每对两两交等于 β，三重交等于 γ。写出由包含排除各项非负以及并概率 ≤ 1 得到的三个不等式。

<details>
<summary>Solution sketch / 解答提示</summary>

β ≥ 0, γ ≥ 0, α ≥ β ≥ γ (from successive differences), and 3α - 3β + γ ≤ 1.

β ≥ 0，γ ≥ 0，α ≥ β ≥ γ（逐级差），以及 3α - 3β + γ ≤ 1。

</details>
