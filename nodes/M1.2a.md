# M1.2a Monotonicity and Simple Bounds / 概率单调性与简单上界

**Prerequisites / 前置**: [M1.1](M1.1.md), [M1.2](M1.2.md)

**Source anchors**: $A\subset B\Rightarrow\Pr(A)\le\Pr(B)$; Boolean / union bound; feasibility of parameters.

---

## What problem are we solving? / 我们要解决什么问题？

Before exact counting or inclusion-exclusion, crude inequalities often rule out impossible parameter values or give quick upper bounds on a union.

在精确计数或包含排除之前，粗不等式常能排除不可能的参数，或给并事件快速上界。

---

## Step 1: Monotonicity / 第一步：单调性

If $A\subseteq B$, then $\Pr(A)\le\Pr(B)$.

Proof sketch: $B=A\cup(B\setminus A)$ disjoint, so $\Pr(B)=\Pr(A)+\Pr(B\setminus A)\ge\Pr(A)$.

Corollary: $\Pr(A\cap B)\le\min(\Pr(A),\Pr(B))$.

---

## Step 2: Union (Boolean) bound / 第二步：并界

$$
\Pr(A\cup B)\le\Pr(A)+\Pr(B),
$$

and more generally $\Pr(\bigcup_i A_i)\le\sum_i\Pr(A_i)$. Equality needs disjointness (or zero overlap probability).

---

## Step 3: Feasibility checks / 第三步：可行性

Given numerical claims, check consistency with monotonicity and $\Pr\le 1$:

- If $A\subset B$ and $\Pr(A)=0.7$, then $\Pr(B)\ge 0.7$ (cannot be $0.5$).
- $\Pr(A\cup B\cup C)\le 1$; each pairwise intersection is $\le$ each single probability.

---

## Step 4: Hand checks / 第四步：手算

$\Pr(A)=0.4$, $\Pr(B)=0.5$, $\Pr(A\cup B)\le 0.9$ by the union bound; exact value needs $\Pr(A\cap B)$.

If $\Pr(A\cup B)=0.95$ and $\Pr(A)=0.6$, then $\Pr(B)\ge 0.95-0.6=0.35$ (from IE rearranged).

---

## Must-build intuitions / 必须建立的直觉

1. Larger sets (in inclusion) cannot have smaller probability.  
2. Union bound is cheap and always valid; often loose.  
3. Parameter problems: first check monotonicity and $\Pr\le 1$ before solving equations.  
4. $\Pr(A\cap B)\le\min(\Pr(A),\Pr(B))$ is immediate from $A\cap B\subset A$.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Treating union bound as equality | Only when disjoint |
| Claiming $\Pr(B)<\Pr(A)$ while $A\subset B$ | Violates monotonicity |
| Ignoring $\Pr\le 1$ when maximising a parameter | Cap at 1 |
| Using $\Pr(A\cap B)\ge\min$ | Wrong direction; use $\le\min$ |

---

## Practice / 练习（选择题）

**1.** If $A\subset B$ and $\Pr(A)=0.7$, which is impossible?

A. $\Pr(B)=0.8$  
B. $\Pr(B)=0.7$  
C. $\Pr(B)=0.5$  
D. $\Pr(B)=1$

<details>
<summary>详细过程 / Solution</summary>

Monotonicity forces $\Pr(B)\ge 0.7$.  
Answer: **C**.
</details>

**2.** Always true:

A. $\Pr(A\cup B)=\Pr(A)+\Pr(B)$  
B. $\Pr(A\cup B)\le\Pr(A)+\Pr(B)$  
C. $\Pr(A\cup B)\ge\Pr(A)+\Pr(B)$  
D. $\Pr(A\cap B)=\Pr(A)+\Pr(B)$

<details>
<summary>详细过程 / Solution</summary>

Union bound / Boolean inequality. Equality only if disjoint.  
Answer: **B**.
</details>

**3.** $\Pr(A\cap B)$ is always

A. $\ge\min(\Pr(A),\Pr(B))$  
B. $\le\min(\Pr(A),\Pr(B))$  
C. $=\Pr(A)\Pr(B)$  
D. $=0$

<details>
<summary>详细过程 / Solution</summary>

$A\cap B\subset A$ and $\subset B$, so $\le$ each, hence $\le\min$.  
Answer: **B**.
</details>

**4.** $\Pr(A)=0.3$, $\Pr(B)=0.4$. The largest possible $\Pr(A\cup B)$ is

A. $0.3$  
B. $0.4$  
C. $0.7$  
D. $1$

<details>
<summary>详细过程 / Solution</summary>

Maximum when intersection is as small as possible; by IE max is $\min(1,\Pr(A)+\Pr(B))=0.7$.  
Answer: **C**.
</details>

**5.** $\Pr(A)=0.3$, $\Pr(B)=0.4$. The smallest possible $\Pr(A\cup B)$ is

A. $0$  
B. $0.3$  
C. $0.4$  
D. $0.7$

<details>
<summary>详细过程 / Solution</summary>

Minimum when one contains the other as much as possible: $\max(\Pr(A),\Pr(B))=0.4$.  
Answer: **C**.
</details>

**6.** If $\Pr(A\cup B\cup C)=1.2$ is claimed, then

A. valid if events overlap little  
B. impossible  
C. requires independence  
D. requires $\Pr=0$ for one event

<details>
<summary>详细过程 / Solution</summary>

Any probability is $\le 1$.  
Answer: **B**.
</details>

**7.** $A\subset B\subset C$, $\Pr(A)=0.2$, $\Pr(C)=0.5$. Which is possible for $\Pr(B)$?

A. $0.1$  
B. $0.2$  
C. $0.6$  
D. $0.9$

<details>
<summary>详细过程 / Solution</summary>

Must have $0.2\le\Pr(B)\le 0.5$.  
Answer: **B**.
</details>

**8.** Union bound $\Pr(\bigcup_{i=1}^{n}A_i)\le\sum\Pr(A_i)$ becomes equality when

A. always  
B. the $A_i$ are pairwise independent  
C. the $A_i$ are pairwise disjoint  
D. $n=2$ only

<details>
<summary>详细过程 / Solution</summary>

Countable/finite additivity for disjoint unions.  
Answer: **C**.
</details>
