# M5.4 Network Reliability / 网络可靠性

**Prerequisites / 前置**: [M1.3](M1.3.md), [M1.6](M1.6.md)

**Source anchors**: series/parallel systems; independent components; path events.

---

## What problem are we solving? / 我们要解决什么问题？

A system of independent components works if certain **paths** from source to sink work. Compute system reliability from component reliabilities.

独立部件组成的网络：源到汇有通路则系统工作；由部件可靠度算系统可靠度。

---

## Step 1: Series / 第一步：串联

All must work: $R=\prod_i p_i$.

---

## Step 2: Parallel / 第二步：并联

At least one works: $R=1-\prod_i(1-p_i)$.

---

## Step 3: General structure / 第三步：一般结构

Path indicators are dependent when paths share edges → inclusion-exclusion or conditioning (see bridge [M7.9](M7.9.md)).

---

## Must-build intuitions / 必须建立的直觉

1. Series multiplies reliabilities.  
2. Parallel uses complement of all-fail.  
3. Shared components induce dependence among path events.  
4. Independence is assumed at the component level, not path level.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Adding path probabilities without IE | Overcount shared structure |
| Treating dependent path indicators as independent | Condition or IE |
| Mixing up-time continuous models without stating | Discrete up/down first |

---

## Practice / 练习（选择题）

**1.** Series of independent components with reliabilities $p_i$:

A. $\sum p_i$  
B. $\prod p_i$  
C. $1-\prod(1-p_i)$  
D. $\max p_i$

<details>
<summary>详细过程 / Solution</summary>

All must work.  
Answer: **B**.
</details>

**2.** Parallel of independent components:

A. $\prod p_i$  
B. $1-\prod(1-p_i)$  
C. $\sum p_i$  
D. $\min p_i$

<details>
<summary>详细过程 / Solution</summary>

Complement of all fail.  
Answer: **B**.
</details>

**3.** Two parallel components $p=0.9$ each. System reliability =

A. $0.81$  
B. $0.99$  
C. $1.8$  
D. $0.9$

<details>
<summary>详细过程 / Solution</summary>

$1-(0.1)^2=0.99$.  
Answer: **B**.
</details>

**4.** Two series components $p=0.9$ each. Reliability =

A. $0.99$  
B. $0.81$  
C. $1.8$  
D. $0.9$

<details>
<summary>详细过程 / Solution</summary>

$0.9\times0.9=0.81$.  
Answer: **B**.
</details>

**5.** Path events sharing an edge are

A. always independent  
B. typically dependent  
C. impossible  
D. parallel only

<details>
<summary>详细过程 / Solution</summary>

Shared randomness.  
Answer: **B**.
</details>

**6.** Component independence means

A. path indicators independent always  
B. edge up-events independent  
C. system always works  
D. $R=1$

<details>
<summary>详细过程 / Solution</summary>

Assumption level.  
Answer: **B**.
</details>

**7.** Inclusion-exclusion on path events is needed when

A. series only  
B. paths are not disjoint in edges  
C. $p_i=1$  
D. never

<details>
<summary>详细过程 / Solution</summary>

Overlapping structure.  
Answer: **B**.
</details>

**8.** Bridge networks are handled by

A. pure series formula only  
B. conditioning on the bridge  
C. ignoring structure  
D. only min-cut without probability

<details>
<summary>详细过程 / Solution</summary>

See M7.9.  
Answer: **B**.
</details>
