# M5.4 Network Reliability Conditional Probability / 网络可靠性条件概率

**Prerequisites / 前置**: [M1.3 Conditional Probability](M1.3.md), [M1.6 Independence](M1.6.md), [M1.2 Inclusion-Exclusion](M1.2.md)

---

## Content / 内容

A path event is expressed as the union of the elementary bridge events that realise that path (direct bridge, upper path, lower path, …). When bridges fail independently the probability of any particular configuration is the product of the individual open/closed probabilities. The conditional probability that a distinguished bridge is open given that the network is connected equals P(bridge open and connected) / P(connected). Inclusion-exclusion or complement arguments simplify the numerator and denominator. Always list every connecting path before writing probabilities.

路径事件表达为实现该路径的基本桥事件的并（直接桥、上路径、下路径…）。桥独立失效时，任一特定配置的概率是各桥开/闭概率的乘积。给定网络连通时某特定桥开启的条件概率等于 P(桥开且连通)/P(连通)。包含排除或补事件可简化分子分母。写概率前始终列出所有连通路径。

## Example / 例子

Five bridges, independent open probability p. East-West connection can occur via bridge 3, or via 1-and-4, or via 2-and-5. The probability of connection is computed by inclusion-exclusion on these three path events.

五座桥，独立开启概率 p。东西连通可通过桥 3，或 1 与 4，或 2 与 5。连通概率通过对这三路径事件做包含排除得到。

## Practice Problem / 练习题

Two independent bridges in parallel, each open with probability 1/2. Find the probability that both are open given that the network is connected.

两座独立并联桥，各以概率 1/2 开启。求给定网络连通时两桥都开启的概率。

<details>
<summary>Solution sketch / 解答提示</summary>

P(both open)=1/4. P(connected)=1−(1/2)^2=3/4. Conditional probability (1/4)/(3/4)=1/3.

P(两桥都开)=1/4。P(连通)=1−(1/2)^2=3/4。条件概率 (1/4)/(3/4)=1/3。

</details>
