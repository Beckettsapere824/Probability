# M4.2a Mean and Variance of the Binomial / 二项分布的期望与方差

**Prerequisites / 前置**: [M3.1 Expectation](M3.1.md), [M3.3 Variance](M3.3.md), [M4.2 Binomial](M4.2.md)

---

## Content / 内容

If X ~ B(n,p) then E(X)=np and Var(X)=np(1−p). Both formulae follow at once by writing X as the sum of n independent Bernoulli indicators and applying linearity (for the mean) and independence (for the variance). The successive-term ratio p(k+1)/p(k) = ((n−k)/(k+1))·(p/(1−p)) helps when enumerating tail probabilities. Never write the binomial variance as simply np.

若 X ~ B(n,p)，则 E(X)=np，Var(X)=np(1−p)。两公式通过把 X 写成 n 个独立 Bernoulli 指示之和，再分别用线性性（均值）与独立性（方差）立即得到。相邻项比值 p(k+1)/p(k) = ((n−k)/(k+1))·(p/(1−p)) 有助于枚举尾概率。不要把二项方差写成 np。

## Example / 例子

X ~ B(10,0.3). E(X)=3, Var(X)=2.1.

X ~ B(10,0.3)。E(X)=3，Var(X)=2.1。
