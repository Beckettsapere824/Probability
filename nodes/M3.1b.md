# M3.1b Tail-Sum Formula for Non-negative Integer Random Variables / 非负整数随机变量的尾和公式

**Prerequisites / 前置**: [M3.1 Expectation Definition and Linearity](M3.1.md)

---

## Content / 内容

If X takes values in the non-negative integers, then E(X) = Σ_{k=1}^∞ P(X ≥ k). The identity follows by writing P(X ≥ k) = Σ_{j=k}^∞ p(j) and changing the order of summation. It is especially convenient for geometric waiting times, order statistics, and indicator counting arguments.

若 X 取非负整数值，则 E(X) = Σ_{k=1}^∞ P(X ≥ k)。恒等式由 P(X ≥ k) = Σ_{j=k}^∞ p(j) 并交换求和次序得到。它对几何等待、次序统计量与指示变量计数特别方便。

The formula requires non-negative integer support; it does not hold for arbitrary real-valued random variables without additional integrability conditions. It can be combined with the law of total expectation.

公式需要非负整数支撑；对任意实值随机变量在无额外可积条件下不成立。可与全期望公式联用。

## Example / 例子

Geometric T with success probability p: P(T ≥ k) = (1-p)^{k-1}. Summing from k=1 to ∞ yields E(T) = 1/p.

成功概率 p 的几何 T：P(T ≥ k) = (1-p)^{k-1}。从 k=1 到 ∞ 求和得 E(T) = 1/p。

## Practice Problem / 练习题

Let X be the number of heads in 3 fair coin tosses. Compute E(X) by the tail-sum formula and verify it equals 1.5.

设 X 为 3 次公平抛币中正面次数。用尾和公式计算 E(X) 并验证等于 1.5。

<details>
<summary>Solution sketch / 解答提示</summary>

P(X≥1)=7/8, P(X≥2)=4/8, P(X≥3)=1/8. Sum = 12/8 = 1.5.
