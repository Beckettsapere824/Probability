# M3.1 Expectation Definition and Linearity / 期望定义与线性性

**Prerequisites / 前置**: [M1.8 Random Variables, PMF, CDF](M1.8.md)

---

## Content / 内容

For a discrete random variable X the expectation is E(X) = Σ x p(x), provided the sum converges absolutely. Linearity holds without any independence assumption: E(aX + b) = a E(X) + b and more generally E(aX + bY) = a E(X) + b E(Y).

离散随机变量 X 的期望为 E(X) = Σ x p(x)（绝对收敛时）。线性性无需任何独立假设：E(aX + b) = a E(X) + b，更一般地 E(aX + bY) = a E(X) + b E(Y)。

When a distribution is given by a table, first verify that the probabilities sum to 1, then compute the weighted sum. Symmetric distributions often allow shortcuts (the mean sits at the centre of symmetry).

表格分布先检查概率和为 1，再算加权和。对称分布常可简化（均值位于对称中心）。

## Example / 例子

X takes values −1,0,1 with probabilities 1/4,1/2,1/4. E(X) = (−1)(1/4)+0+(1)(1/4) = 0.

X 取值 −1,0,1，概率 1/4,1/2,1/4。E(X) = (−1)(1/4)+0+(1)(1/4) = 0。

## Practice Problem / 练习题

A discrete random variable has PMF p(1)=0.2, p(2)=0.5, p(5)=0.3. Compute E(X).

离散随机变量 PMF p(1)=0.2, p(2)=0.5, p(5)=0.3。求 E(X)。

<details>
<summary>Solution sketch / 解答提示</summary>

E(X) = 1·0.2 + 2·0.5 + 5·0.3 = 2.7.

E(X) = 1·0.2 + 2·0.5 + 5·0.3 = 2.7。

</details>
