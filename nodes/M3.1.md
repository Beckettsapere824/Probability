# M3.1 Expectation and Linearity / 期望与线性性

**Prerequisites / 前置**: [M1.8 Discrete RV, PMF, CDF](M1.8.md)

**Source anchors**: SDST2601A discrete expectation; indicator method; continuous $\int x f(x)\,dx$ deferred to [M8.1](M8.1.md); tail-sum formula for non-negative integer RVs.

---

## What problem are we solving? / 我们要解决什么问题？

A random variable spreads probability over many values. We want one number that answers: “in the long run, under this distribution, what average value do we see?” That number is the **expectation**. It is not “the most likely value” (that is the mode) and not always the midpoint of the range.

随机变量把概率铺在许多取值上。我们要一个数回答：「在该分布下，长期平均会看到什么值？」这就是**期望**。它不是「最可能的值」（那是众数），也不一定是取值范围的中点。

---

## Step 1: Discrete definition / 第一步：离散定义

$$E(X)=\sum_{x} x\,p_{X}(x),$$

when $\sum |x|p_{X}(x)<\infty$ (absolute convergence). If the absolute sum diverges, we say the expectation does not exist (even if a principal-value sum looks finite).

Interpretation: weighted average of the values, weights = probabilities.

绝对收敛时定义；解释为以概率为权的加权平均。绝对和发散则称期望不存在。

---

## Step 2: Linearity — the workhorse / 第二步：线性性——主力工具

$$E(aX+bY)=aE(X)+bE(Y)$$

for constants $a,b$, **with no independence assumption**. This is why indicator tricks are powerful:

$$X=\sum_{j=1}^{n}I_{j} \implies E(X)=\sum_{j=1}^{n}E(I_{j})=\sum_{j=1}^{n}\Pr(I_{j}=1).$$

Binomial mean $np$, expected number of fixed points in a random permutation, expected number of empty boxes — all are linearity + indicators, no need to write the full PMF of $X$.

**不要求独立。** 指示变量法：二项均值、错排期望固定点数、空盒期望数，都只需线性性，不必写出 $X$ 的完整 PMF。

---

## Step 3: Tail-sum formula (non-negative integer $X$) / 第三步：尾和公式

If $X$ takes values in $\{0,1,2,\ldots\}$,

$$E(X)=\sum_{n=0}^{\infty}\Pr(X>n)=\sum_{n=1}^{\infty}\Pr(X\ge n).$$

Proof sketch: write $\Pr(X\ge n)=\sum_{k=n}^{\infty}p(k)$ and change order of summation.  
Exams ask you to **prove** this and then apply it to coupon-collector or geometric-type waits.

$X$ 取非负整数时 $E(X)=\sum_{n\ge 0}\Pr(X>n)$。试卷常要求证明并用于优惠券/几何类等待。

---

## Step 4: Functions of $X$ (LOTUS preview) / 第四步：$X$ 的函数

$$E\bigl(g(X)\bigr)=\sum_{x} g(x)\,p(x)$$

when the sum converges absolutely — you do **not** need the PMF of $g(X)$ first. Full continuous LOTUS in [M3.2](M3.2.md) / continuous chapter.

---

## Step 5: Hand calculations / 第五步：手算

**Symmetric table.** $X\in\{-1,0,1\}$ with $p=1/4,1/2,1/4$: $E(X)=0$.

**Asymmetric.** $p(1)=0.2$, $p(2)=0.5$, $p(5)=0.3$:  
$E(X)=1\cdot 0.2+2\cdot 0.5+5\cdot 0.3=2.7$.

Always verify $\sum p=1$ before averaging.

---

## Must-build intuitions / 必须建立的直觉

1. Expectation is a probability-weighted average, not “middle of the support”.  
2. Linearity never needs independence — use it aggressively with indicators.  
3. $E(X)$ may fail to exist if tails are too heavy.  
4. For non-negative integer $X$, tail sum is often easier than $\sum k p(k)$.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Equal-weight average of values | Use $p(x)$ as weights |
| Thinking linearity needs independence | It does not |
| Computing $E(g(X))$ via PMF of $g(X)$ only | LOTUS: $\sum g(x)p(x)$ |
| Continuous $X$ still using $\sum$ | Switch to $\int x f(x)\,dx$ |

---

## Worked exam-style example / 考试风格例题

**Problem.** $X$ takes values $0,1,2,\ldots$ and $E(X)$ exists. Prove $E(X)=\sum_{n=0}^{\infty}\Pr(X>n)$.

**Solution.**  
$E(X)=\sum_{k=1}^{\infty}k\,p(k)=\sum_{k=1}^{\infty}\sum_{n=0}^{k-1}p(k)=\sum_{n=0}^{\infty}\sum_{k=n+1}^{\infty}p(k)=\sum_{n=0}^{\infty}\Pr(X>n)$.

**Application.** Coupon collector with 3 types, equal probability: waiting time $N$ has $E(N)=3(1+1/2+1/3)$ via successive geometric waits (or tail methods).

## Practice / 练习

1. $p(1)=0.2$, $p(2)=0.5$, $p(5)=0.3$. $E(X)$?

2. $n$ people, random permutation. Expected number of fixed points?

3. Why does $E(X+Y)=E(X)+E(Y)$ hold even if $X,Y$ are dependent?

<details>
<summary>Solution sketches / 解答提示</summary>

1. $2.7$.

2. Indicators $I_{j}=1$ if position $j$ fixed; $E(I_{j})=1/n$; sum → $E=1$.

3. Linearity is an identity on the joint double sum / integral; no independence enters.
