# M3.1 Expectation and Linearity / 期望与线性性

**Prerequisites / 前置**: [M1.8 Random Variables, PMF, CDF](M1.8.md)

**Source / 来源**: SDST2601A discrete expectation; continuous analogue uses $\int x f(x)\,dx$ in [M8.1](M8.1.md)

---

## What problem are we solving? / 我们要解决什么问题？

A random variable has many possible values. We want a single summary—“average outcome in the long run under this distribution”—that works even when the experiment is not repeated, as long as the PMF is known.

随机变量有许多可能值。我们要一个单一摘要——「在该分布下的长期平均结果」——只要 PMF 已知即可用。

---

## Step 1: Definition (discrete) / 第一步：定义

$$E(X)=\sum_{x} x\,p(x),$$

when the sum converges absolutely. Interpretation: weighted average of values, weights = probabilities.

绝对收敛时定义；解释为以概率为权的加权平均。

---

## Step 2: Linearity / 第二步：线性性

$$E(aX+b)=aE(X)+b, \qquad E(aX+bY)=aE(X)+bE(Y).$$

**No independence required.** This is why indicator tricks and binomial means are easy: write $X$ as a sum and pull $E$ through.

**不需要独立。** 因此指示变量与二项均值好算：写成和再把 $E$ 拿进去。

---

## Step 3: Hand calculation / 第三步：手算

$X\in\{-1,0,1\}$ with probabilities $1/4,1/2,1/4$: $E(X)=0$ (symmetry).

Table rule: first check $\sum p=1$, then $\sum x p(x)$.

---

## Common pitfalls / 易错点

- Averaging the values with equal weight when probabilities differ.  
- Assuming linearity needs independence.  
- For continuous $X$, using $\sum$ instead of $\int x f(x)\,dx$.

---

## Practice / 练习

$p(1)=0.2$, $p(2)=0.5$, $p(5)=0.3$. Compute $E(X)$.

<details>
<summary>Solution sketch / 解答提示</summary>

$E(X)=1\cdot 0.2+2\cdot 0.5+5\cdot 0.3=2.7$.

</details>
