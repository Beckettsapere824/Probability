## Content / 内容

### Definition 5.8

\(X\) has a **normal (Gaussian)** distribution if

\[
f(x) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\Bigl(-\frac{(x-\mu)^2}{2\sigma^2}\Bigr), \quad x\in\mathbb{R},
\]
with \(\sigma>0\). Write \(X \sim N(\mu,\sigma^2)\).

\[
E(X)=\mu, \qquad \mathrm{Var}(X)=\sigma^2, \qquad
M_X(t)=\exp\bigl(\mu t + \tfrac12 \sigma^2 t^2\bigr).
\]

### Standardization

\[
Z = \frac{X-\mu}{\sigma} \sim N(0,1).
\]

CDF of \(Z\) is \(\Phi(z)=\Pr(Z\le z)\). Course table lists \(\Phi(z)\) for \(z\ge 0\); use symmetry

\[
\Phi(-z)=1-\Phi(z).
\]

### Interval probabilities

\[
\Pr(a \le X \le b) = \Phi\Bigl(\frac{b-\mu}{\sigma}\Bigr) - \Phi\Bigl(\frac{a-\mu}{\sigma}\Bigr).
\]

Empirical landmarks (from notes): about 95.4% of mass lies in \(\mu\pm 2\sigma\).

### Symmetry

\[
\Pr(X \le \mu - x) = \Pr(X \ge \mu + x).
\]

## Example / 例子

**Standard calculation pattern (Examples 5.9–5.10).**  
Convert event about \(X\) into event about \(Z\), look up \(\Phi\), apply symmetry for negative arguments.

---

## Common pitfalls / 易错点

- Writing \(N(\mu,\sigma)\) when the second parameter is variance \(\sigma^2\) (notation conflict across books).
- Forgetting to standardize before using the Φ table.
- Using table left-tail values as right-tail without \(1-\Phi\).

## Practice Problem / 练习题

\(X \sim N(10, 4)\) (variance 4). Find \(\Pr(8 < X < 14)\) in terms of \(\Phi\).

<details>
<summary>Solution sketch / 解答提示</summary>

\(\sigma=2\).  
\(\Pr\bigl(\frac{8-10}{2} < Z < \frac{14-10}{2}\bigr)=\Pr(-1<Z<2)=\Phi(2)-\Phi(-1)=\Phi(2)-(1-\Phi(1))=\Phi(2)+\Phi(1)-1\).

</details>
