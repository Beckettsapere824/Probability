# M4.2 Binomial Distribution / 二项分布

**Prerequisites / 前置**: [M0.3 Combinations](M0.3.md), [M3.1 Expectation](M3.1.md), [M4.1 Bernoulli](M4.1.md)

---

## Content / 内容

X ~ Binomial(n,p) counts the number of successes in n independent Bernoulli(p) trials. The PMF is
p(k) = C(n,k) p^k (1−p)^{n−k}, k=0,1,…,n.
Normalisation follows at once from the binomial theorem. The same distribution arises as the number of red balls among three draws when each ball is independently red with probability p.

X ~ Binomial(n,p) 计数 n 次独立 Bernoulli(p) 试验中的成功次数。PMF 为
p(k) = C(n,k) p^k (1−p)^{n−k}，k=0,1,…,n。
归一化由二项式定理立即得到。同一分布也出现在每次独立以概率 p 为红的三球问题中。

Tail probabilities are evaluated either by direct summation or via the complement. The ratio of successive terms p(k+1)/p(k) = ((n−k)/(k+1))·(p/(1−p)) is useful for recursive computation.

尾概率可直接累加或用补事件。相邻项比值 p(k+1)/p(k) = ((n−k)/(k+1))·(p/(1−p)) 便于递推计算。

## Example / 例子

X ~ B(3,1/2). P(X=2) = C(3,2)(1/2)^3 = 3/8.

X ~ B(3,1/2)。P(X=2) = C(3,2)(1/2)^3 = 3/8。

## Practice Problem / 练习题

A fair coin is tossed 5 times. Find P(exactly 3 heads).

公平硬币抛 5 次。求恰好 3 次正面的概率。

<details>
<summary>Solution sketch / 解答提示</summary>

C(5,3)(1/2)^5 = 10/32 = 5/16.

C(5,3)(1/2)^5 = 10/32 = 5/16。

</details>
