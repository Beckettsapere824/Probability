# M4.5a Distinguishing the Two Negative-Binomial Definitions / 负二项分布的定义区分

**Prerequisites / 前置**: [M4.5 Negative Binomial](M4.5.md)

---

## Content / 内容

Definition A (trial number of the r-th success): the random variable T equals n when the first n−1 trials contain exactly r−1 successes and the n-th trial is a success. PMF = C(n−1,r−1) p^r (1−p)^{n−r}. Mean = r/p.

定义 A（第 r 次成功的试验编号）：随机变量 T 等于 n 当且仅当前 n−1 次恰有 r−1 次成功且第 n 次成功。PMF = C(n−1,r−1) p^r (1−p)^{n−r}。均值 = r/p。

Definition B (number of failures before the r-th success): the random variable F counts failures only. Mean = r(1−p)/p. The two definitions must never be mixed inside the same calculation. When writing a solution, explicitly label whether the variable is total trials or number of failures.

定义 B（第 r 次成功前的失败次数）：随机变量 F 只计失败。均值 = r(1−p)/p。两种定义绝不能在同一计算中混用。写解答时明确标注变量是总试验次数还是失败次数。

## Example / 例子

r=2, p=1/2. Under definition A, E(T)=4. Under definition B, E(F)=2.

r=2，p=1/2。定义 A 下 E(T)=4。定义 B 下 E(F)=2。

## Practice Problem / 练习题

State the mean of the number of failures before the 5th success when p=0.2.

当 p=0.2 时，第 5 次成功前的失败次数的均值是多少？

<details>
<summary>Solution sketch / 解答提示</summary>

5·(0.8)/0.2 = 20.

5·(0.8)/0.2 = 20。

</details>
