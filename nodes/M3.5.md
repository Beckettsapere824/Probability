# M3.5 Probability Intervals and Table Accumulation / 概率区间与表格累加

**Prerequisites / 前置**: [M3.3 Variance](M3.3.md), [M1.8 Random Variables, PMF, CDF](M1.8.md)

---

## Content / 内容

To evaluate P(|X − μ| ≤ 2σ) first compute μ and σ, convert the absolute-value inequality into the closed interval [μ − 2σ, μ + 2σ], then sum every probability mass that lies inside the interval. End-points must be examined for inclusion because the distribution is discrete.

计算 P(|X − μ| ≤ 2σ) 时先求 μ 与 σ，把绝对值不等式转为闭区间 [μ − 2σ, μ + 2σ]，再累加落在区间内的全部概率质量。因分布离散，端点是否包含必须检查。

Do not replace a discrete table by a continuous normal approximation unless the problem explicitly permits it. The complementary probability outside the interval is 1 minus the interior sum.

除非题目明确允许，不要用连续正态近似替代离散表格。区间外的互补概率为 1 减区间内和。

## Example / 例子

μ = 3, σ = 1. Interval [1,5]. Sum p(1)+…+p(5).

μ = 3，σ = 1。区间 [1,5]。累加 p(1)+…+p(5)。

## Practice Problem / 练习题

X takes values 0,1,2,3,4 with equal probability 1/5. Compute P(|X − μ| ≤ 2σ).

X 取值 0,1,2,3,4 各概率 1/5。求 P(|X − μ| ≤ 2σ)。

<details>
<summary>Solution sketch / 解答提示</summary>

μ = 2, Var(X) = 2, σ = √2 ≈ 1.41, 2σ ≈ 2.83. Interval [−0.83,4.83] contains all mass, so the probability is 1.

μ = 2，Var(X) = 2，σ = √2 ≈ 1.41，2σ ≈ 2.83。区间 [−0.83,4.83] 包含全部质量，概率为 1。

</details>
