# M6.3 Independent Repeated Trials, Complements and Waiting Times / 独立重复试验、补事件与等待时间

**Prerequisites / 前置**: [M4.4 Geometric](M4.4.md), [M1.2 Complement](M1.2.md)

---

## Content / 内容

The number of sequences of length n on a six-faced die with no two consecutive faces equal is 6·5^{n−1}. Consequently the probability that a random sequence of length n contains at least one pair of consecutive equal faces is 1−(5/6)^{n−1}. Solving the inequality 1−(5/6)^{n−1} > α for the smallest integer n uses logarithms and careful handling of inequality direction. The same complement technique evaluates “at least one” or “at least two” events for independent trials; geometric waiting-time comparisons appear when two competing success streams are examined.

六面骰长度为 n 且无连续同面的序列数为 6·5^{n−1}。因此随机长度为 n 的序列至少含一对连续同面的概率为 1−(5/6)^{n−1}。解不等式 1−(5/6)^{n−1} > α 求最小整数 n 时使用对数并注意不等号方向。同一补事件技巧计算独立试验的“至少一个”或“至少两个”事件；当考察两条竞争成功流时出现几何等待时间比较。

## Example / 例子

Smallest n such that the probability of at least one consecutive repeat exceeds 1/2: solve (5/6)^{n−1} < 1/2 → n−1 > log(1/2)/log(5/6) ≈ 3.8, so n ≥ 5.

使至少一次连续重复的概率超过 1/2 的最小 n：解 (5/6)^{n−1} < 1/2 → n−1 > log(1/2)/log(5/6) ≈ 3.8，故 n ≥ 5。

## Practice Problem / 练习题

Find the smallest n such that a sequence of n fair coin tosses has probability greater than 0.9 of containing at least one head.

求最小 n，使 n 次公平抛币序列至少含一次正面的概率大于 0.9。

<details>
<summary>Solution sketch / 解答提示</summary>

1−(1/2)^n > 0.9 → (1/2)^n < 0.1 → n > log2(10) ≈ 3.32, so n=4.
