# M6.2 Stationary Distribution and Long-Run Frequency / 平稳分布与长期频率

**Prerequisites / 前置**: [M6.1 Two-State Markov Chain](M6.1.md)

---

## Content / 内容

A stationary distribution π satisfies the linear system πP = π together with the normalisation π_W + π_L = 1 and the requirement that every component be non-negative. For an irreducible positive-recurrent chain the long-run proportion of time spent in each state equals the corresponding stationary probability and is independent of the initial distribution. The system is solved by ordinary linear algebra.

平稳分布 π 满足线性方程组 πP = π，以及归一化 π_W + π_L = 1 和各分量非负。对不可约正常返链，长期停留在各状态的时间比例等于相应平稳概率，且与初始分布无关。方程组用普通线性代数求解。

## Example / 例子

P = [[0.6,0.4],[0.3,0.7]]. Solving yields π_W = 3/7, π_L = 4/7. The long-run frequency of W is therefore 3/7.

P = [[0.6,0.4],[0.3,0.7]]。解得 π_W = 3/7，π_L = 4/7。因此 W 的长期频率为 3/7。

## Practice Problem / 练习题

Find the stationary distribution of P = [[0.8,0.2],[0.5,0.5]].

求 P = [[0.8,0.2],[0.5,0.5]] 的平稳分布。

<details>
<summary>Solution sketch / 解答提示</summary>

π_1 = 0.8π_1 + 0.5π_2, π_1+π_2=1 → π_1=5/7, π_2=2/7.

π_1 = 0.8π_1 + 0.5π_2，π_1+π_2=1 → π_1=5/7，π_2=2/7。

</details>
