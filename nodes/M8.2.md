# M8.2 Normalizing a pdf / pdf 归一化练习

**Prerequisites / 前置**: [M8.1](M8.1.md)

---

## What problem are we solving? / 我们要解决什么问题？

Given an un-normalized non-negative $g$, find $c$ so $f=cg$ is a pdf, then compute interval probabilities.

---

## Steps / 分步

1. Solve $\int g=1/c$ (or $\int cg=1$).  
2. $F(x)=\int_{-\infty}^{x}f$.  
3. $\Pr(a<X<b)=F(b)-F(a)$.

---

## Practice / 练习

$g(x)=x$ on $(0,2)$. Find $c$ for $f=cg$.

<details><summary>Answer</summary>$\int_0^2 x\,dx=2$, so $c=1/2$.</details>
