# M5.5 First-Step Analysis / 第一步分析

**Prerequisites / 前置**: [M1.4](M1.4.md)

**Source anchors**: absorption probabilities; condition on first transition; linear systems.

---

## What problem are we solving? / 我们要解决什么问题？

In a Markov-like setting with absorbing goals, let $h_i=$ probability of eventual absorption in a goal set starting from $i$. Condition on the **first step** to obtain linear equations for the $h_i$.

吸收问题：从 $i$ 出发最终被目标吸收的概率 $h_i$，对第一步条件化得线性方程。

---

## Step 1: Boundary / 第一步：边界

$h_g=1$ for goal absorbing states; $h_f=0$ for failure absorbing states.

---

## Step 2: Interior equations / 第二步：内部方程

For transient $i$:
$$h_i=\sum_j P_{ij}h_j.$$

---

## Step 3: Hand idea / 第三步：思路

Gambler’s ruin: states $0,\ldots,N$, absorb at $0$ and $N$. Fair game ⇒ $h_i=i/N$ for absorption at $N$.

---

## Must-build intuitions / 必须建立的直觉

1. First-step analysis = total probability on the next state.  
2. Boundaries encode success/failure.  
3. Solve the linear system for all transient states together.  
4. Same pattern works for expected time to absorption with $+1$ per step.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Forgetting boundary values | Set $h$ on absorbing states first |
| Writing equations only for one $i$ | Full system |
| Using stationary $\pi$ instead of absorption $h$ | Different target |
