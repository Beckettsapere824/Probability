# M5.5 Pattern Competition, First-Step Analysis and Absorbing Markov Chains / 模式竞争、首步分析与吸收马尔可夫链

**Prerequisites / 前置**: [M1.6 Independence](M1.6.md), [M0.8 Matrices](M0.8.md), [M4.4 Geometric](M4.4.md)

---

## Content / 内容

When two patterns (for example HHH and HTH) compete to appear first in a sequence of i.i.d. coin tosses, the state space is defined by the current matched prefix of either pattern. First-step equations are written for the probability that a designated pattern wins starting from each state. Absorbing states correspond to the completed patterns. Overlaps of a pattern with itself or with its rival must be encoded in the transition structure; a naïve comparison of waiting-time expectations is insufficient.

当两个模式（例如 HHH 与 HTH）在一列 i.i.d. 抛币中竞争首先出现时，状态空间由当前已匹配的任一模式前缀定义。对每个状态写出指定模式获胜概率的首步方程。吸收态对应已完成的模式。模式与自身或与对手的重叠必须编码进转移结构；仅比较等待时间期望是不够的。

## Example / 例子

States: ∅, H, HH, HTH (absorb), HHH (absorb). From HH a T moves to the state that already matches the first letter of HTH, while an H moves to the absorbing HHH.

状态：∅、H、HH、HTH（吸收）、HHH（吸收）。从 HH 出发，T 转移到已匹配 HTH 首字母的状态，H 转移到吸收态 HHH。

## Practice Problem / 练习题

Why can the probability that HHH appears before HTH not be obtained simply by comparing 1/p^3 with the waiting time of HTH?

为什么“HHH 先于 HTH 出现”的概率不能仅通过比较 1/p^3 与 HTH 的等待时间得到？

<details>
<summary>Solution sketch / 解答提示</summary>

The patterns overlap with themselves and with each other; the first-step analysis automatically accounts for the overlaps, whereas raw waiting-time comparison does not.

模式与自身及彼此重叠；首步分析自动计入重叠，而原始等待时间比较不能。

</details>
