# M5.2 Medical Diagnosis: Sensitivity, Specificity, Bayes / 医学诊断：敏感度、特异度、贝叶斯

**Prerequisites / 前置**: [M1.4 Law of Total Probability](M1.4.md), [M1.5 Bayes’ Theorem](M1.5.md)

---

## Content / 内容

Sensitivity is P(+|D), specificity is P(−|D^c). The false-positive rate is therefore P(+|D^c)=1−specificity. Bayes’ theorem converts these quantities into the positive predictive value:
P(D|+) = P(+|D)P(D) / [P(+|D)P(D)+P(+|D^c)P(D^c)].
When a threshold parameter must be recovered, the posterior is written as a fractional equation in that parameter. Base-rate neglect is the systematic error of ignoring a small prior prevalence.

敏感度为 P(+|D)，特异度为 P(−|D^c)。因此假阳性率为 P(+|D^c)=1−特异度。贝叶斯定理把这些量转化为阳性预测值：
P(D|+) = P(+|D)P(D) / [P(+|D)P(D)+P(+|D^c)P(D^c)]。
需要反解阈值参数时，把后验写成该参数的分式方程。基础率谬误是忽略很小先验患病率的系统性错误。

Always write the four conditional probabilities explicitly before substituting numbers.

代入数字前始终显式写出四个条件概率。

## Example / 例子

Sensitivity 0.95, specificity 0.90, prevalence 0.01. P(+)≈0.1085, P(D|+)≈0.0876.

敏感度 0.95，特异度 0.90，患病率 0.01。P(+)≈0.1085，P(D|+)≈0.0876。

## Practice Problem / 练习题

Sensitivity 0.99, specificity 0.95, prevalence 0.02. Compute P(D|+).

敏感度 0.99，特异度 0.95，患病率 0.02。求 P(D|+)。

<details>
<summary>Solution sketch / 解答提示</summary>

P(+)=0.99·0.02+0.05·0.98=0.0688. P(D|+)=0.0198/0.0688≈0.288.
