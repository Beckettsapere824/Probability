# M2.13 Grid Paths / 网格路径

**Prerequisites / 前置**: [M0.3](M0.3.md)

**Source anchors**: lattice paths; $\binom{a+b}{a}$ right/up sequences.

---

## What problem are we solving? / 我们要解决什么问题？

Number of shortest paths from $(0,0)$ to $(a,b)$ using only unit right and unit up steps.

从 $(0,0)$ 到 $(a,b)$、只向右/向上的最短路径数。

---

## Step 1: Sequence count / 第一步：序列计数

$$\binom{a+b}{a}=\binom{a+b}{b}.$$

---

## Step 2: Hand check / 第二步：手算

To $(2,3)$: $\binom{5}{2}=10$.

---

## Step 3: Obstacles / 第三步：障碍

Blocked squares need IE or recursion; unrestricted first.

---

## Must-build intuitions / 必须建立的直觉

1. Path = word with $a$ R and $b$ U.  
2. Binomial coefficient chooses positions.  
3. Same count as sequences of steps with fixed counts.  
4. Catalan numbers arise when paths stay above a diagonal — later refinement.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Using $a!b!$ without binomial | Overcount order |
| Allowing left/down in “shortest” | Not shortest |
| $\binom{a}{b}$ wrong arguments | Total $a+b$ |

---
