# M1.2 Complement, Union, Inclusion-Exclusion / 补事件、并交事件、包含排除

**Prerequisites / 前置**: [M1.1 Sample Space, Events, Probability Axioms](M1.1.md)

---

## Content / 内容

The complement rule is P(A^c) = 1 - P(A). It is the most common way to compute “at least one” probabilities: P(at least one) = 1 - P(none).

补事件公式：P(A^c) = 1 - P(A)。它是计算“至少一个”概率最常用的方法：P(至少一个) = 1 - P(都不)。

The two-event inclusion-exclusion formula is P(A ∪ B) = P(A) + P(B) - P(A ∩ B). For three events:
P(A ∪ B ∪ C) = P(A) + P(B) + P(C) - P(A ∩ B) - P(A ∩ C) - P(B ∩ C) + P(A ∩ B ∩ C).

两事件包含排除：P(A ∪ B) = P(A) + P(B) - P(A ∩ B)。三事件：
P(A ∪ B ∪ C) = P(A) + P(B) + P(C) - P(A ∩ B) - P(A ∩ C) - P(B ∩ C) + P(A ∩ B ∩ C)。

P(A ∩ B) = 0 means the events are mutually exclusive. Events defined by products of differences being zero can be rewritten as unions and then handled by inclusion-exclusion.

P(A ∩ B) = 0 表示互斥。由差的乘积为零定义的事件可拆成并事件再算。

## Example / 例子

P(A) = 0.3, P(B) = 0.4, P(A ∩ B) = 0.1. Then P(A ∪ B) = 0.6 and P(A^c ∩ B^c) = 1 - 0.6 = 0.4.

P(A) = 0.3，P(B) = 0.4，P(A ∩ B) = 0.1。则 P(A ∪ B) = 0.6，P(A^c ∩ B^c) = 1 - 0.6 = 0.4。

## Practice Problem / 练习题

Three events satisfy P(A) = P(B) = P(C) = 0.5, pairwise intersections 0.2, triple intersection 0.1. Find P(A ∪ B ∪ C).

三事件满足 P(A) = P(B) = P(C) = 0.5，两两交 0.2，三重交 0.1。求 P(A ∪ B ∪ C)。

<details>
<summary>Solution sketch / 解答提示</summary>

0.5+0.5+0.5 - 0.2-0.2-0.2 + 0.1 = 1.5 - 0.6 + 0.1 = 1.0.

0.5+0.5+0.5 - 0.2-0.2-0.2 + 0.1 = 1.5 - 0.6 + 0.1 = 1.0。

</details>
