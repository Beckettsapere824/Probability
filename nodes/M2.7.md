# M2.7 Random Permutations and Relative Order / 随机排列与相对顺序

**Prerequisites / 前置**: [M0.3 Factorials, Permutations, Combinations](M0.3.md)

---

## Content / 内容

In a uniformly random permutation the relative order of any fixed set of r distinct positions is itself uniformly random among the r! possible orders. Consequently the probability that r specified elements appear in a prescribed relative order is 1/r!.

均匀随机排列中，任意固定 r 个位置的相对次序在 r! 种可能中均匀。因此指定 r 个元素按给定相对次序出现的概率为 1/r!。

The phrase “A before C before E” does not require the three elements to be consecutive; only their mutual order matters. Irrelevant elements may be ignored when computing relative-order probabilities.

“A 在 C 前且 C 在 E 前”不要求三者相邻；只关心它们的相对次序。计算相对次序概率时可忽略无关元素。

## Example / 例子

In a random permutation of {A,B,C,D,E} the probability that A appears before C and C appears before E is 1/3! = 1/6.

{A,B,C,D,E} 的随机排列中，A 在 C 前且 C 在 E 前的概率为 1/3! = 1/6。

## Practice Problem / 练习题

Five distinct books are placed at random on a shelf. What is the probability that book A is to the left of book B?

五本不同的书随机放在书架上。书 A 在书 B 左边的概率是多少？

<details>
<summary>Solution sketch / 解答提示</summary>

Among the two possible relative orders of A and B each is equally likely, so the probability is 1/2.

A 与 B 的两种相对次序等可能，故概率为 1/2。

</details>
