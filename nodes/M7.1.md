# M7.1 Patent Lifetime and Linear Cost Transformation / 专利寿命与成本线性变换

**Prerequisites / 前置**: [M3.1 Expectation](M3.1.md), [M3.3 Variance](M3.3.md), [M3.4 Linear Transformations](M3.4.md), [M3.5 Probability Intervals](M3.5.md)

---

## Content / 内容

Given a discrete lifetime table one first computes μ = E(X) and σ = sd(X). The cost is the linear function C = 13000 + 2000 X. Linearity immediately supplies E(C) = 13000 + 2000 μ and sd(C) = 2000 σ. Interval probabilities such as P(|X−μ|≤2σ) are obtained by converting the absolute-value statement into a closed interval and summing the table masses that fall inside it. Always compute the moments of X first, then apply the linear transformation; the standard deviation of cost carries the same monetary unit as the cost itself.

给定离散寿命表后先计算 μ = E(X) 与 σ = sd(X)。成本是线性函数 C = 13000 + 2000 X。线性性立即给出 E(C) = 13000 + 2000 μ 与 sd(C) = 2000 σ。区间概率如 P(|X−μ|≤2σ) 通过把绝对值陈述转为闭区间并累加落在其中的表格质量得到。始终先算 X 的矩，再施加线性变换；成本标准差与成本本身同货币单位。

## Example / 例子

If μ=5 and σ=2 then E(C)=23000, sd(C)=4000. The interval |X−5|≤4 becomes [1,9].

若 μ=5 且 σ=2，则 E(C)=23000，sd(C)=4000。区间 |X−5|≤4 变为 [1,9]。

## Practice Problem / 练习题

X takes values 1,2,3 each with probability 1/3. Cost C=1000+500X. Find E(C) and sd(C).

X 取值 1,2,3 各概率 1/3。成本 C=1000+500X。求 E(C) 与 sd(C)。

<details>
<summary>Solution sketch / 解答提示</summary>

E(X)=2, Var(X)=2/3, sd(X)=√(2/3). E(C)=2000, sd(C)=500√(2/3).

E(X)=2，Var(X)=2/3，sd(X)=√(2/3)。E(C)=2000，sd(C)=500√(2/3)。

</details>
