# M1.8 Discrete Random Variables, PMF, CDF / 离散随机变量、PMF、CDF

**Prerequisites / 前置**: [M1.1 Sample Space, Events, Axioms](M1.1.md)

**Source anchors**: SDST2601A Ch4 discrete RV; bridge to continuous [M8.1](M8.1.md); endpoint care in $F(b)-F(a)$.

---

## What problem are we solving? / 我们要解决什么问题？

Events are subsets of $\Omega$. We often care about a **number** attached to each outcome — sum of two dice, number of defectives, indicator of disease. A **random variable** packages that number so we can talk about its distribution once, without renaming events every time.

事件是 $\Omega$ 的子集。我们常常关心每个结果上的**数字**——两骰之和、次品数、是否患病。**随机变量**把该数字打包，从而一次说清它的分布。

---

## Step 1: Discrete random variable / 第一步：离散随机变量

A discrete random variable $X$ is a function $X:\Omega\to\mathbb{R}$ whose range is **countable** (finite or listable as $x_1,x_2,\ldots$). The events we care about become $\{X=x\}$, $\{X\le x\}$, $\{X\in A\}$.

Technically $\{X\le x\}=X^{-1}((-\infty,x])$ must be an event (measurable); in this course every reasonable function on a finite/countable $\Omega$ is allowed.

离散随机变量：值域可数的 $X:\Omega\to\mathbb{R}$。关心的事件变成 $\{X=x\}$、$\{X\le x\}$ 等。

---

## Step 2: Probability mass function (PMF) / 第二步：概率质量函数

$$p_X(x)=\Pr(X=x).$$

Requirements:

1. $p_X(x)\ge 0$ for every $x$.  
2. $\sum_x p_X(x)=1$ (sum over the countable support).

For any set $A\subset\mathbb{R}$,

$$\Pr(X\in A)=\sum_{x\in A}p_X(x).$$

The PMF completely determines the distribution of a discrete $X$.

$p\ge 0$ 且求和为 1。集合概率 = 集合上质量之和。PMF 完全决定离散 $X$ 的分布。

---

## Step 3: Cumulative distribution function (CDF) / 第三步：分布函数

$$F_X(x)=\Pr(X\le x)=\sum_{u\le x}p_X(u).$$

Properties:

- Non-decreasing.  
- Right-continuous.  
- $F(-\infty)=0$, $F(+\infty)=1$.  
- Jump at $x$ equals $p_X(x)$: $p_X(x)=F(x)-F(x-)$.

**Interval rule (discrete — watch endpoints):**

$$\Pr(a<X\le b)=F(b)-F(a),$$

$$\Pr(a\le X\le b)=F(b)-F(a-),$$

$$\Pr(a\le X<b)=F(b-)-F(a-).$$

When $a,b$ are not mass points the distinctions vanish; when they are, off-by-one errors lose marks.

$F$ 右连续、跳跃高度 = $p(x)$。离散时区间端点开闭要小心。

---

## Step 4: Hand example / 第四步：手算

$X\in\{0,1,2\}$ with $p(0)=1/4$, $p(1)=1/2$, $p(2)=1/4$.

| Range of $x$ | $F(x)$ |
|--------------|--------|
| $x<0$ | $0$ |
| $0\le x<1$ | $1/4$ |
| $1\le x<2$ | $3/4$ |
| $x\ge 2$ | $1$ |

$\Pr(0<X\le 1)=F(1)-F(0)=3/4-1/4=1/2$ (equals $p(1)$).

---

## Step 5: Link to continuous / 第五步：与连续的衔接

Continuous variables replace point masses by a **density** $f$ and sums by integrals ([M8.1](M8.1.md)). The CDF $F$ is still defined the same way; only the way of building $F$ changes (integral of $f$ instead of sum of $p$).

连续用密度与积分代替点质量与求和；CDF 定义方式相同。

---

## Must-build intuitions / 必须建立的直觉

1. RV = number attached to each outcome; discrete = countable range.  
2. PMF puts mass on points; must sum to 1.  
3. CDF accumulates mass from the left; jumps recover the PMF.  
4. Endpoint care: $F(b)-F(a)$ is $\Pr(a<X\le b)$ for discrete $X$.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Writing $p(x)$ for continuous $X$ | Use density $f$ and intervals |
| $\Pr(X<b)$ vs $\Pr(X\le b)$ at a mass point | Differ by $p(b)$ |
| PMF not summing to 1 | Always check normalisation |
| Treating $F(x)=\Pr(X<x)$ | Standard definition is $\le$ |

---

## Worked exam-style example / 考试风格例题

**Problem.** $p(1)=0.2$, $p(2)=0.5$, $p(3)=0.3$. Find $F(2.5)$ and $\Pr(X\ge 2)$.

**Solution.** $F(2.5)=p(1)+p(2)=0.7$. $\Pr(X\ge 2)=p(2)+p(3)=0.8$.

## Practice / 练习

1. Same $p$ as above. $\Pr(1<X\le 3)$?

2. Sketch $F$ for a fair die $X\in\{1,\ldots,6\}$.

3. Why is $F$ right-continuous rather than left-continuous by convention?

<details>
<summary>Solution sketches / 解答提示</summary>

1. $F(3)-F(1)=1-0.2=0.8$ (or $p(2)+p(3)$).

2. Step function jumping $1/6$ at each integer $1,\ldots,6$.

3. So that $F(x)=\Pr(X\le x)$ includes the mass at $x$; jumps are visible from the right.

</details>
