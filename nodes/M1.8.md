# M1.8 Random Variables, PMF, CDF / 随机变量、PMF、CDF

**Prerequisites / 前置**: [M1.1 Sample Space, Events, Probability Axioms](M1.1.md)

---

## Content / 内容

A discrete random variable X is a function from the sample space to a countable set of real numbers. Its probability mass function (PMF) is p(x) = P(X = x). The PMF satisfies p(x) ≥ 0 and Σ_x p(x) = 1.

离散随机变量 X 是从样本空间到可数实数集的函数。其概率质量函数（PMF）为 p(x) = P(X = x)。PMF 满足 p(x) ≥ 0 且 Σ_x p(x) = 1。

The cumulative distribution function (CDF) is F(x) = P(X ≤ x) = Σ_{u ≤ x} p(u). F is non-decreasing and right-continuous, with F(-∞) = 0 and F(+∞) = 1. Interval probabilities are recovered by differencing: P(a < X ≤ b) = F(b) - F(a).

累积分布函数（CDF）为 F(x) = P(X ≤ x) = Σ_{u ≤ x} p(u)。F 单调不减、右连续，F(-∞) = 0，F(+∞) = 1。区间概率由差分得到：P(a < X ≤ b) = F(b) - F(a)。

Given a PMF one obtains the CDF by cumulative summation; given a CDF the jump sizes recover the PMF.

由 PMF 累加得 CDF；由 CDF 的跳跃高度得 PMF。

## Example / 例子

X takes values 0,1,2 with probabilities 1/4, 1/2, 1/4. Then F(x) = 0 for x < 0, 1/4 for 0 ≤ x < 1, 3/4 for 1 ≤ x < 2, and 1 for x ≥ 2.

X 取值 0,1,2，概率 1/4, 1/2, 1/4。则 F(x) 在 x < 0 为 0，0 ≤ x < 1 为 1/4，1 ≤ x < 2 为 3/4，x ≥ 2 为 1。

## Practice Problem / 练习题

A discrete random variable has PMF p(k) = c / 2^k for k = 1,2,3,… . Find c and write F(3).

离散随机变量 PMF 为 p(k) = c / 2^k，k = 1,2,3,…。求 c 并写出 F(3)。

<details>
<summary>Solution sketch / 解答提示</summary>

Σ_{k=1}^∞ c/2^k = c · (1/2)/(1-1/2) = c = 1, so c = 1. F(3) = p(1)+p(2)+p(3) = 1/2 + 1/4 + 1/8 = 7/8.

Σ_{k=1}^∞ c/2^k = c · (1/2)/(1-1/2) = c，故 c = 1。F(3) = 1/2 + 1/4 + 1/8 = 7/8。

</details>
