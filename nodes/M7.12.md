# M7.12 Non-adjacent Couples via IE / 夫妻不相邻容斥

**Prerequisites / 前置**: [M2.18](M2.18.md), [M2.19](M2.19.md), [M1.2](M1.2.md)

**Source anchors**: gap method; inclusion-exclusion for “at least one couple together”; circular vs linear seating.

---

## What problem are we solving? / 我们要解决什么问题？

Seat $n$ couples so that **no couple sits together** (or count the complementary event). Gap methods place one gender first; IE subtracts arrangements where specified couples are adjacent (treat as blocks).

$n$ 对夫妻不相邻就座。先排一方留空位；或对「至少一对相邻」做容斥（粘成块）。

---

## Step 1: Gap method (linear sketch) / 第一步：空位法

Seat all $n$ of one group: $n!$ orders, gaps for partners. Choosing gaps between the first gender forces separation when partners sit in those gaps only.

---

## Step 2: IE view / 第二步：容斥

Let $A_i=$ couple $i$ sits together. Treat couple $i$ as a single block: internal factor $2$, units become $2n-1$ linear. Inclusion-exclusion on $\bigcup A_i$; complement gives none together.

---

## Step 3: Hand scale / 第三步：量级

For small $n$ enumerate or apply IE fully; factorial growth makes pattern recognition important on exams.

---

## Must-build intuitions / 必须建立的直觉

1. “No couple together” = complement of “at least one together” or direct gap placement.  
2. Adjacent couple → block of size 2 with internal $2$ orders.  
3. Circular seating: fix one position to remove rotational symmetry.  
4. IE sign alternates with the number of glued couples.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Forgetting internal $2$ orientations of a block | Multiply by $2^k$ for $k$ blocks |
| Linear formula on a circular table | Fix rotation or use $(n-1)!$ |
| Double-counting gaps | Draw the seats |
