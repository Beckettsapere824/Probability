# M4.4a Geometric Support Conventions / 几何支撑约定

**Prerequisites / 前置**: [M4.4](M4.4.md)

**Source anchors**: trials until first success vs failures before first success; means $1/p$ vs $(1-p)/p$.

---

## What problem are we solving? / 我们要解决什么问题？

Two common supports for “geometric”: number of **trials** until first success $\{1,2,\ldots\}$ vs number of **failures** before first success $\{0,1,\ldots\}$. Means differ.

几何分布两种支撑：到首次成功的试验次数 vs 首次成功前的失败次数；期望不同。

---

## Step 1: Trials version / 第一步：试验次数版

$\Pr(T=k)=q^{k-1}p$, $k=1,2,\ldots$. $E(T)=1/p$.

---

## Step 2: Failures version / 第二步：失败次数版

$\Pr(Y=k)=q^{k}p$, $k=0,1,\ldots$. $E(Y)=q/p$. Note $T=Y+1$.

---

## Step 3: Exam hygiene / 第三步：考试注意

Always read which convention the problem uses; both are called “geometric” in different texts.

---

## Must-build intuitions / 必须建立的直觉

1. Same experiment, two labelings of the count.  
2. Means differ by 1.  
3. Memoryless property holds for both (with care on the support).  
4. Negative binomial inherits the same convention choice.

---

## Common pitfalls / 易错点

| Pitfall | Fix |
|--------|-----|
| Using $1/p$ when the variable is failures | Use $q/p$ |
| Mixing PMF formulas across conventions | Match support |
| Claiming both means equal | They differ by 1 |
