# M3.4a Distribution Mapping under a Linear Transformation / 线性变换的分布映射

**Prerequisites / 前置**: [M3.4 Linear Transformations](M3.4.md)

---

## Content / 内容

If Y = aX + b with a ≠ 0, the PMF of Y is obtained by the change-of-variable formula p_Y(y) = p_X((y − b)/a). The support of Y is the support of X shifted by b and scaled by a. Expectation and variance transform exactly as in the preceding node. When a < 0 the order of the support points is reversed.

若 Y = aX + b 且 a ≠ 0，则 Y 的 PMF 由换元公式 p_Y(y) = p_X((y − b)/a) 得到。Y 的支撑是 X 的支撑平移 b 并缩放 a。期望与方差的变换与上一节点完全相同。当 a < 0 时支撑点的顺序反转。

The mapping is used for currency conversion, unit changes, and any affine re-expression of a discrete random variable.

该映射用于货币换算、单位变换以及离散随机变量的任意仿射重表达。

## Example / 例子

X takes 1,2,3 each with probability 1/3. Y = 2X − 1 takes 1,3,5 each with probability 1/3.

X 取值 1,2,3 各概率 1/3。Y = 2X − 1 取值 1,3,5 各概率 1/3。

## Practice Problem / 练习题

X has PMF p(0)=1/2, p(1)=1/2. Let Y = −3X + 4. Write the PMF of Y.

X 的 PMF 为 p(0)=1/2, p(1)=1/2。设 Y = −3X + 4。写出 Y 的 PMF。

<details>
<summary>Solution sketch / 解答提示</summary>

When X=0, Y=4; when X=1, Y=1. Thus p_Y(4)=1/2, p_Y(1)=1/2.

X=0 时 Y=4；X=1 时 Y=1。故 p_Y(4)=1/2，p_Y(1)=1/2。

</details>
