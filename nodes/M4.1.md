# M4.1 Bernoulli Distribution / Bernoulli 分布

**Prerequisites / 前置**: [M3.1 Expectation](M3.1.md)

---

## Content / 内容

A Bernoulli random variable takes only the values 0 and 1, with P(X=1)=p and P(X=0)=1−p. Its expectation is p and its variance is p(1−p). Every indicator of an event is a Bernoulli random variable; the Bernoulli distribution is therefore the building block of the binomial distribution and of indicator arguments.

Bernoulli 随机变量只取 0 和 1，P(X=1)=p，P(X=0)=1−p。期望为 p，方差为 p(1−p)。任何事件的指示都是 Bernoulli 随机变量；因此 Bernoulli 分布是二项分布与指示变量论证的基本单元。

Typical applications include a single diagnostic test result and a single independent trial.

典型应用包括单次诊断测试结果与单次独立试验。

## Example / 例子

A fair coin: p=1/2, E(X)=1/2, Var(X)=1/4.

公平硬币：p=1/2，E(X)=1/2，Var(X)=1/4。

## Practice Problem / 练习题

A test detects a disease with probability 0.9 when the disease is present. Model the detection indicator and give its mean and variance.

某检测在疾病存在时以概率 0.9 检出。为检出指示建模并给出其均值与方差。

<details>
<summary>Solution sketch / 解答提示</summary>

Bernoulli(0.9), mean 0.9, variance 0.9·0.1=0.09.

Bernoulli(0.9)，均值 0.9，方差 0.9·0.1=0.09。

</details>
