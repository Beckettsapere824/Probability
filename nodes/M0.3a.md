# M0.3a Boundary Conventions for Binomial Coefficients / 组合数边界约定

**Prerequisites / 前置**: [M0.3 Factorials, Permutations, Combinations](M0.3.md)

---

## Content / 内容

By convention we set C(n,k) = 0 whenever k < 0 or k > n. This keeps formulas valid without extra case distinctions. In particular C(n,0) = C(n,n) = 1 for every non-negative integer n.

约定：当 k < 0 或 k > n 时，C(n,k) = 0。这样公式在边界处仍然成立，不必额外分情况。特别地，对任意非负整数 n 有 C(n,0) = C(n,n) = 1。

These conventions appear constantly when writing PMFs (the support must make the binomial coefficient non-zero), when summing series (lower limits can safely start from 0), and in inclusion-exclusion arguments where “selecting more objects than available” contributes zero.

这些约定在写 PMF（支撑集必须使组合数非零）、求和（下限可从 0 起）以及容斥（“选出超过可用数量”贡献为零）中反复出现。

When deriving the PMF of an order statistic or when simplifying a combinatorial sum, first write the legal range of the index k; outside that range the binomial coefficient is automatically zero.

推导次序统计量 PMF 或化简组合求和时，先明确指标 k 的合法范围；范围外组合数自动为零。

## Example / 例子

C(5,7) = 0, C(5,-1) = 0, C(5,0) = 1, C(5,5) = 1. The sum Σ_{k=0}^{10} C(5,k) equals Σ_{k=0}^{5} C(5,k) = 2^5 = 32 because the extra terms vanish.

C(5,7) = 0，C(5,-1) = 0，C(5,0) = 1，C(5,5) = 1。求和 Σ_{k=0}^{10} C(5,k) 等于 Σ_{k=0}^{5} C(5,k) = 2^5 = 32，因为多余项为零。

## Practice Problem / 练习题

Write the support of the hypergeometric PMF that draws k red balls from an urn with R red and N-R blue balls, sampling n balls without replacement. Use the boundary convention to express the range of k cleanly.

写出从装有 R 个红球、N-R 个蓝球的瓮中无放回抽取 n 个球时，抽到 k 个红球的超几何 PMF 的支撑。用边界约定干净地表达 k 的范围。

<details>
<summary>Solution sketch / 解答提示</summary>

k must satisfy max(0, n-(N-R)) ≤ k ≤ min(n,R). Outside this interval at least one binomial coefficient is zero, so the probability is automatically zero.

k 必须满足 max(0, n-(N-R)) ≤ k ≤ min(n,R)。区间外至少一个组合数为零，概率自动为零。

</details>
