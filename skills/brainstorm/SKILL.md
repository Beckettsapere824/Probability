# brainstorm

## When to use
User request is ambiguous, multi-way, or lacks a single obvious path.

## Steps
1. Restate the goal in one sentence.
2. List 2–4 concrete options.
3. For each: pros, cons, risk, effort.
4. Recommend one with rationale.
5. Record direction in progress.md before coding.
